## Target Student Gifts

Legacy crafting guidance: stage-two crafting is the reliable place to target gifts preferred by a specific student. Set crafting stage to at least two, then use student recommendation or the recommended-priority shortcut in stage-two settings.

| Goal                           | Recommendation                                                    |
| ------------------------------ | ----------------------------------------------------------------- |
| Get gifts for a target student | Use stage-two student recommendation                              |
| Save materials                 | Lower crafting count first and inspect logs/node choices          |
| Avoid accidental spending      | Do not enable stage-three crafting until the strategy is verified |
