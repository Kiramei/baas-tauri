## Basic Settings

| Control               | Meaning and accepted values                                                                                                                        | Exported field                       |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| Collect rewards       | Collect accumulated Cafe income when the Cafe task runs                                                                                            | `cafe_reward_collect_hour_reward`    |
| Use invitation ticket | Permit ticket use during the Cafe reward flow; switching it off is not the same as disabling every independent invitation task                     | `cafe_reward_use_invitation_ticket`  |
| Student outfit change | Allow an invitation that replaces the student's alternate outfit when the game asks                                                                | `cafe_reward_allow_exchange_student` |
| Duplicate invite      | Allow inviting a student already present when the duplicate-invite prompt appears                                                                  | `cafe_reward_allow_duplicate_invite` |
| Cafe 2                | Include the second Cafe and display its separate settings tab; enable only after it is unlocked in game                                            | `cafe_reward_has_no2_cafe`           |
| Patting rounds        | Integer 4–15; input is clamped to this range. More rounds can reduce missed interactions but take longer. An empty intermediate value is not saved | `cafe_reward_affection_pat_round`    |
| Patting style         | Normal interaction or Drag Gift; these choose the interaction method, not the crafting material strategy                                           | `patStyle`                           |

Turning Cafe 2 off hides its tab without turning it into a separate delete action. Re-enable it to edit that Cafe's strategy. These switches describe behavior, not proof that a ticket or student is available.

## Cafe 1 and Cafe 2 Invitations

Each Cafe has an independent invitation mode, starred position and named-student list. Cafe 2's tab exists only while the Basic Cafe 2 switch is enabled.

<img
  className="baas-screenshot"
  src="/media/desktop/en/conditional-cafe-named.png"
  alt="Cafe 1 invitation by name with students in selection order"
/>

| Mode              | Behavior                                             | Conditional control                          |
| ----------------- | ---------------------------------------------------- | -------------------------------------------- |
| Lowest affection  | Invite by ascending affection order in the game list | No named-student or starred-position control |
| Highest affection | Invite by descending affection order                 | No named-student or starred-position control |
| Starred           | Invite from the game's starred list                  | Starred position 1–5                         |
| By name           | Try configured students in list order                | Student chips and Add Student                |

For Cafe N, the exported fields are `cafe_reward_inviteN_criterion`,
`cafe_reward_inviteN_starred_student_position` and `favorStudentN`, where N is
1 or 2. Starred position is a position in the game list, not a student identifier.
An empty named list falls back to lowest-affection invitation in the inspected
backend; it does not mean “never invite.”

## Student Selector

Choose By name, then Add Student. Search filters the names supplied by the
backend for the selected game server. The game-server naming convention is
independent of the app's interface language; an English UI can show Chinese
names for a CN profile.

Click a student to add it; click a selected student again to remove it. New
selections append to the preference list. The chip's remove icon also removes
that entry. Selections update the automatically saved draft as you click;
closing the selector does not undo them.
To put a target first, build the list in the desired order.

<img
  className="baas-screenshot"

Closing and reopening the selector within this category keeps the search text.
No matches leaves an empty list; clear the search to show all candidates again.
Filtering does not remove students already selected.

## Schedule and Check

The Cafe reward task and the Cafe 1/Cafe 2 invitation tasks are separate scheduler
entries. Inspect each enabled entry, its next run and pre/post tasks. Setting
both Cafe strategies to the same student is a preference, not a guarantee of
two successful invitations or unlimited affection; game availability and
cooldowns still apply.

For a focused affection plan, align the selected student in Cafe, Lessons and
stage-two Crafting. Run one configured task first and check the invitation
method, detected student name, ticket availability and outcome in logs. A
recognized student in the selector is not evidence that the account owns it
or can invite it now.
