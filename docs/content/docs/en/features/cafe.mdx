## Targeted Affection Strategy

Legacy guidance still applies:

| Goal                                        | Method                                                                                                                                          |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Invite a target student                     | Use invite-by-name, or favorite only the target student and use favorite-student invite                                                         |
| Pat a target student multiple times per day | Configure both cafe 1 and cafe 2 for the target; disable automatic invitation-ticket use; enable the related cafe invitation tasks in Scheduler |
| Reduce wrong invites                        | Avoid long candidate lists; confirm whether alternate outfits are allowed                                                                       |

To maximize one student's affection, configure cafe, lessons, and crafting together: cafe handles pats and invitations, lessons target the student when possible, and crafting prioritizes preferred gifts.
