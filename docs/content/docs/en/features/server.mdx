## Game Server

The server selector is **disabled for an existing profile**. Choose the correct server when creating a profile; create another profile to use a different game package. Changing UI language does not change the game server.

| Choice            | Game client             |
| ----------------- | ----------------------- |
| Official (CN)     | Mainland China official |
| Bilibili (CN)     | Mainland China Bilibili |
| Global            | Global                  |
| Global (Teen)     | Global teen             |
| Korea (ONE store) | Korean ONE store        |
| Japan             | Japanese                |

The saved field is `server`. An available choice does not guarantee that every current event or task is implemented for that server.

## Address, Port or USB Serial

| Input                           | Client interpretation                                            |
| ------------------------------- | ---------------------------------------------------------------- |
| Both address and port populated | ADB `host:port`; the port must be an integer from `0` to `65535` |
| Only one field populated        | A device/USB serial rather than a host/port pair                 |
| Both empty                      | Invalid; this section does not commit                            |

Leading/trailing whitespace is trimmed. Port zero passes client validation but is not evidence of a usable ADB endpoint. Local emulator addresses commonly use `127.0.0.1`; each running instance can have a different port. Use the actual emulator configuration, not a guessed port formula.

Valid edits save automatically to `adbIP` and `adbPort`. They configure the game device, **not** the separate client-to-backend service connection in application Settings.

## Detect ADB

1. Start the intended device/emulator and enable its ADB debugging.
2. Open the detection icon beside the port.
3. Choose **Detect ADB** inside the dialog. Merely opening the dialog does not scan.
4. Wait for results, then select the intended address to fill the editor and close the dialog.

An address containing a colon is split at its last colon into address and port; a serial without one fills the address and clears the port. Verify the result before starting a task.

The empty-results message also appears before the first scan. During detection the button shows loading and is disabled. No results can mean the emulator is closed, debugging is disabled, the device is unauthorized/offline, or the backend's scan does not cover that endpoint. Confirm the exact serial with `adb devices` when diagnosing rather than treating any result as the correct instance.

## Android

The Android app selects a local installed game package from the profile server and uses Shizuku with `android_local`. Desktop ADB fields are not a substitute for Android authorization or a way to select another phone. Follow [Android Client](../guide/android) for the local-game setup.
