System settings affect the Tauri client experience and do not directly change individual game task strategy.

<img
  className="baas-screenshot"
  src="/en/settings-interface-preferences.png"
  alt="Settings interface section with background, language, UI scale, remote display decoder, log scrolling, assets, BAComet, and low performance mode"
/>

| Setting                | Purpose                                            |
| ---------------------- | -------------------------------------------------- |
| Theme / accent color   | Adjust client appearance                           |
| Background / opacity   | Personalize the window                             |
| Language               | Switch app UI language                             |
| UI scale               | Resize the interface                               |
| Remote display decoder | Fix black screen, stutter, or compatibility issues |
| Low performance mode   | Reduce animation and overhead                      |
