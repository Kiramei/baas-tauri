## Stage Input Rules

Legacy backend input rules are still useful for understanding stage parameters:

| Scenario      | Format                              | Example                                           |
| ------------- | ----------------------------------- | ------------------------------------------------- |
| Normal stages | Area or area-stage                  | `15,16-3` runs area 15 and stage 16-3             |
| Hard stages   | Same as normal stages               | `15,16-3` runs H15 and H16-3                      |
| Main story    | Chapter numbers separated by commas | `2,3,6` means chapter 1, chapter 2, final chapter |

Stage automation checks SSS, challenge tasks, and gift collection where applicable. Completed stages are skipped. Some hard stages in chapters 1-13 may be entered more than once to satisfy all goals; later chapters usually finish in one pass.

## Event Recognition

Event stages are generally stable for Story / Quest / Challenge structures. Challenge stages that are not route-map stages may require manual boss or combat handling.
