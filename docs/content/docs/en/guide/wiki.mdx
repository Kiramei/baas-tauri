The standalone documentation site is generated from `baas-tauri/docs` with Fumadocs. BAAS Tauri opens it in your system's default browser.

## Open the Documentation

Choose **Help → Documentation** in the desktop titlebar. The app no longer embeds a Wiki page or displays a Docs item in the sidebar.

Choose **Help → About BAAS**, or click the navigation logo, to open the same About dialog with client, backend, connection, and project information.

## Languages

The documentation site maintains Chinese and English. Its own language menu controls the language independently of the app.

## Local Development URL

Local development usually runs at:

```text
http://localhost:3000/docs/zh/
http://localhost:3000/docs/en/
```

Set `VITE_BAAS_DOCS_URL` when building the app to change its documentation link. The former `VITE_BAAS_WIKI_URL` override remains supported for existing deployments.

## Opening Failures

If the documentation does not open:

- Open the documentation URL in a browser to confirm network or local dev server availability.
- For GitHub Pages, confirm Pages is enabled and `NEXT_PUBLIC_BASE_PATH` matches the repository Pages path.
- For local development, confirm the Next dev server is running under `docs`.
- Confirm that your system has a default browser configured. The app shows an error when the native browser opener fails.
