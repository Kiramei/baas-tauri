---
title: Sign In and Reset the Key
---

On first use, follow the page to set a **Key**. Later, sign in with that Key or a remembered session. This is the backend login credential, separate from a MirrorChyan key or game account password.

While signed in, open **Preferences → General → Login / Key → Reset Key**, enter the new value twice, and confirm. Success invalidates all sessions and remembered logins; profiles remain. Reset requires `/health` to advertise `auth.key_reset_supported: true`. Update an older backend if that capability is missing.

Never post Keys, cookies, Telegram tokens, or logs containing them in public issues.
