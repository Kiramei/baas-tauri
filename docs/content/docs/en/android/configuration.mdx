Config uses search and a category selector above the inline editor. Valid changes save automatically; undo/redo is beside the heading. [Editing Configuration](../guide/configuration) explains invalid drafts and history. Android omits the desktop Emulator category. Script hides desktop screenshot/control selectors and uses `android_local` internally.

| Setting | Operation |
| ------- | --------- |
| [Cafe](../features/cafe) | By-name mode shows students; starred invitation offers positions 1–5 |
| [Lessons](../features/lesson) | Enable preferred students to show the ordered list; disabling retains selections |
| [Crafting](../features/crafting) | Stage count controls visible tabs; stage two has student recommendations and seven material rules |
| [Formation](../features/team) | The method chooses the visible attribute grid; sidebar order hides both |
| [Sweeps](../features/sweeps) | Edit stage/count rows; the student helper appends associated hard stages |

Tasks contains the shared single-list scheduler, per-task switches, timing/detail controls and workflow view. Bulk actions affect the full list even when search hides rows. Configure spending and deletion risks before enabling tasks; [Scheduler](../guide/scheduler) explains timing and relationships.

  className="baas-screenshot baas-mobile-screenshot"

Settings has five categories: General, Appearance, Connection & runtime, Updates, and Logs. Android no longer exposes desktop Shortcuts. General provides [Plugins](../features/plugins); Appearance controls Home's resource strip. Task running and backend updating have separate floating controls.
