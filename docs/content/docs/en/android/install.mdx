---
title: Install and Prepare
---

Download a trusted Android build from the project's [Releases](https://github.com/Kiramei/baas-tauri/releases). Match the device's real architecture, not only the game's architecture. Allow installation from the chosen browser/file manager if Android asks. The APK declares a minimum of Android 7.0/API 24; native game capture requires Android 8.0/API 26 or newer. Meeting these versions still requires checking the device's privileged-display support.

Keep network access available on first launch. Confirm **Stable** to install the upstream BAAS backend, or select **Development** to use `Kiramei/baas-dev`. Later backend updates follow the channel saved in Settings. The startup page exposes five stages:

| Stage                         | What happens                                                                       |
| ----------------------------- | ---------------------------------------------------------------------------------- |
| Application data              | Prepare app-private directories and handle supported legacy-data migration/backups |
| Runtime installation          | Check embedded Python, download/install the backend and apply Android adapters     |
| Local service                 | Start Python in the dedicated backend service process                              |
| Connection verification       | Establish the authenticated encrypted client/backend session                       |
| Configuration synchronization | Load profiles and tasks; OCR initialization can continue in the background         |

Expand a stage to inspect its stdout/stderr terminal. A preparing indicator is not a completed installation. Preserve the full error output before retrying. Do not force-close during download, extraction or an update.

Ordinary runtime/profile data lives in app-private storage; granting broad shared-storage access is not the general fix for startup. Uninstalling/clearing app data can remove that runtime and profiles, so export needed profiles first.
