The top strip selects profiles. Android Home hides the add and profile action buttons and disables long-press profile/global menus; switch to Tasks or Config to create, import or manage profiles. Give a new profile a name and select the server matching the installed game. The server is locked afterward; use another profile for another package. Imports preserve existing profiles and give conflicting names a numbered suffix.

Home, Tasks, Config and Preferences are bottom navigation items. The central play/stop button controls the selected **scheduler**, not just the preview. Home's separate play button starts the game background display without starting scheduled tasks. Start with all resource-consuming tasks disabled until their configuration is checked.

| Profile server    | Required installed package             |
| ----------------- | -------------------------------------- |
| Official (CN)     | `com.RoamingStar.BlueArchive`          |
| Bilibili (CN)     | `com.RoamingStar.BlueArchive.bilibili` |
| Global            | `com.nexon.bluearchive`                |
| Global (Teen)     | `com.nexon.bluearchiveteen`            |
| Korea (ONE store) | `com.nexon.bluearchiveone`             |
| Japan             | `com.YostarJP.BlueArchive`             |

The server-to-package mapping is authoritative. Installing a different regional client does not satisfy it. The app reports a missing/unsupported game rather than using whichever installed package happens to come first.
