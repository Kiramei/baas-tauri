## Maintenance Model

The old local Wiki is no longer the primary documentation surface. The canonical source is `baas-tauri/docs`, generated by Fumadocs. The Tauri Docs page loads this web documentation site by default and can detach it into a standalone "Wiki Documentation" window.

## Runtime Relationship

```mermaid
flowchart LR
  User["User / Profile"] --> Client["BAAS Tauri Desktop"]
  Client --> Home["Home Controls"]
  Client --> Scheduler["Scheduler"]
  Client --> Config["Independent Feature Config"]
  Client --> Docs["Web Docs / Wiki"]
  Scheduler --> Backend["BAAS Backend Service"]
  Config --> Backend
  Backend --> ADB["ADB / Emulator"]
  Backend --> Game["Blue Archive Client"]
  Backend --> Client
```
