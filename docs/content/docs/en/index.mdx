## Get Started

1. [Install the client and connect the backend](./guide/install).
2. [Understand the workspace](./guide/interface) and select or create a [profile](./features/profile).
3. Configure the [server](./features/server), [device](./features/emulator) and [script methods](./features/script).
4. [Edit task behavior](./guide/configuration), then [enable and schedule tasks](./guide/scheduler).
5. Start a small set of tasks and inspect [runtime state and logs](./features/home-runtime).

For local Android automation, begin with [Android Client](./guide/android).
