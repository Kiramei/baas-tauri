配置页顶部有搜索和分类选择器，有效修改自动保存，标题旁可撤销/重做。非法草稿和历史规则见[编辑配置](../guide/configuration)。Android 不提供桌面“模拟器”分类；脚本隐藏桌面截图/控制选择器，内部使用 `android_local`。

| 设置 | 操作 |
| ---- | ---- |
| [咖啡厅](../features/cafe) | 按名称邀请时显示学生列表；收藏邀请提供位置 1–5 |
| [日程](../features/lesson) | 启用偏好学生后显示可排序列表，关闭后保留选择 |
| [制造](../features/crafting) | 阶段数决定可见标签；二阶段提供学生推荐与七种材料规则 |
| [编队](../features/team) | 方式决定显示哪张属性表，侧栏顺序方式隐藏两张表 |
| [扫荡](../features/sweeps) | 按行编辑关卡和次数；学生辅助选择追加对应困难关卡 |

任务页使用共用的单列表调度器，包含任务开关、时间/详情和工作流视图。搜索隐藏部分行时，批量操作仍影响完整列表；先确认消费与删除风险。时间和依赖规则见[任务调度](../guide/scheduler)。

偏好包含通用、外观、连接与运行时、更新、日志五类；Android 已移除桌面快捷键分类。通用页提供[插件](../features/plugins)入口，外观中的资源开关控制主页资源条。调度控件保留；后端更新准备与日志集中到启动页，Android 不再显示底部独立更新日志面板。
