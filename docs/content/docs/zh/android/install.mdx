---
title: 安装与准备
---

从项目 [Releases](https://github.com/Kiramei/baas-tauri/releases) 获取可信 Android 构建，按设备真实架构选择，而非只看游戏架构。Android 提示时，为所用浏览器/文件管理器允许安装。APK 声明的最低版本为 Android 7.0/API 24；原生游戏采集需要 Android 8.0/API 26 及以上。满足版本要求后，仍需检查设备是否支持特权显示。

首次启动时请保持网络可用。默认选中**稳定版**，确认后安装上游 BAAS 后端。也可选择**开发版**使用 `Kiramei/baas-dev`。后续后端更新使用偏好中保存的通道。准备页会在进入首页前持续显示安装、资源验证与更新进度：

| 阶段         | 实际工作                                          |
| ------------ | ------------------------------------------------- |
| 应用数据     | 准备私有目录，处理受支持的旧数据迁移与备份        |
| 安装运行环境 | 检查内嵌 Python，下载/安装后端并应用 Android 适配 |
| 启动本地服务 | 在独立后端服务进程中启动 Python                   |
| 验证连接     | 建立经过身份验证的加密客户端/后端会话             |
| OCR 运行时与模型 | 启动所需原生 OCR，验证识别模型后再开放首页 |
| 脚本资源 | 检查静态配置、RGB 特征目录与图片资源 |
| 同步配置 | 完成已认证的配置档与任务同步 |
| 后端更新检查 | 遵循保存的通道及更新策略，更新后等待新后端准备就绪再恢复调度状态 |

展开阶段可查看 stdout/stderr 终端。显示“准备中”不代表安装完成；当前后端确认所需资源就绪前不会进入首页，失败保留在准备页并提供日志和重试。重试前保留完整错误输出，下载、解压或更新时不要强行关闭。

版本检查因网络失败，或仍在等待长时间运行的脚本时，只有本地资源已经验证且尚未修改后端文件，才可明确选择**使用已验证的本地资源继续**；更新应用或重启一旦失败，必须重试准备，不能用此入口跳过恢复。OCR/资源准备最多等待十分钟，更新后新就绪另有十五分钟期限。启动和定时 APK 检查静默进行，安装 APK 仍需系统确认。

正常运行时和配置保存在应用私有目录，广泛共享存储权限不是启动失败的通用修复。卸载或清除数据可能移除运行时和配置档，操作前先导出需要的配置。
