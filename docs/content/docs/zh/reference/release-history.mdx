本页记录 BAAS Tauri 桌面端、Android 端、更新器、文档站和运行时相关的版本变化。遇到升级后的异常时，先确认当前版本，再对照对应版本的“影响范围”和“升级建议”排查。

## v0.0.9

安装包、签名和发布状态以 [GitHub Releases](https://github.com/Kiramei/baas-tauri/releases) 为准。

- 新增共用插件工作区，提供囤体、自动推图、装备规划、库存搜索棋盘计算和主页编辑；外部 ZIP 需要按配置档确认代码信任。
- WebUI 提供浏览器登录、已认证 Key 重置及 Docker 部署；重置会使所有已有登录失效，保留配置档。
- 桌面、Android 和 WebUI 增加后端提交记录；帮助菜单提供客户端发布记录。移除旧 `baas-cdn` 来源。
- 补充竞技场到顶停止、推图简单模式与主线章节、咖啡厅交互等待、飞书/企业微信/Telegram 通知等配置。旧后端缺少字段时，对应新增控件禁用。
- 原生 Windows 新建 PC 配置后设置桌面截图与控制方式；macOS 增加共享内存通道，Linux 修正窗口外观与渲染。
- Android 增加同会话原生全屏手动操作、自动化输入优先级、计算插件进程，调整导航及运行/更新控件。真机与模拟器验证范围见 [Android 指南](../guide/android)，不承诺所有设备和任务已通过验收。
- 文档补齐中英文使用与接口说明，修复搜索，展示图改用深色 WebP。

升级前导出配置档。插件和新增脚本字段还依赖匹配的后端；Docker 的界面和依赖需通过新镜像更新。

## v0.0.8-rc

预发布：2026-09-04。新增可编辑调度工作流、最小化到托盘、扩展战斗与好友清理编辑器、Windows 共享内存，以及下载源恢复和启动界面修复。工作流操作原有调度数据，布局独立保存。

该 RC 的 Android、WebUI 和更新器发布范围见[对应发布说明](https://github.com/Kiramei/baas-tauri/releases/tag/v0.0.8-rc)。好友清理编辑器的筛选项仍取决于实际后端实现，使用前阅读[删除风险](../features/maintenance#好友清理)。

## v0.0.7

发布日期：2026-07-14

v0.0.7 重点加入原生 Android 客户端、可恢复的服务传输层、系统诊断和通知能力，并修复多处 Android 启动、更新和前端渲染问题。

### 新增能力

| 模块 | 详细信息 |
| --- | --- |
| Android 客户端 | 新增 Android 打包、内置 Python 后端、移动端配置页和设置页、无障碍自动化桥接、前台服务控制、通知栏脚本开关、Android 更新器和 arm64 APK 发布流程。 |
| 服务传输 | 新增可选择的前端传输方式；桌面端优先支持命名管道；WebSocket 和命名管道共享传输生命周期事件，并能在后端断开后自动恢复。 |
| 诊断与通知 | 新增前端系统日志收集、系统日志设置、脚本生命周期通知、服务状态通知、内联终端输出和更清晰的更新器流程状态。 |

### 改进

- 优化 React 渲染架构，减少不必要渲染，并保留未保存的配置草稿。
- 改善主页、调度、设置、配置、安装器、Wiki 和响应式布局。
- Android 开发链路新增热开发、CSS 兼容处理、后端同步、启动交接、UIAutomator 桥接、运行时安装和重启处理。
- 更新器能显示 Android 更新字节进度和后端更新日志；失败的 SHA 探测不再阻塞交互。
- 发布流程增加签名 Android APK、传输构建检查、前端传输测试和质量工作流。

### 修复

- 修复 Android 启动渲染、后端重连与重启、更新后重启应用、配置编码、Wiki 渲染、图标按钮对齐和本地自动化桥接问题。
- 修复桌面端启动空白帧、Tauri 开发启动、调度配置黑屏和配置草稿丢失。
- 修复脚本通知快照、更新器终端嵌入、服务日志作用域和传输恢复边界问题。
- 补齐多语言翻译，并修复阻塞式 SHA 源测试。

### 升级建议

- Android 用户优先查看 Android 安装、权限、前台服务和通知栏脚本开关状态。
- 桌面用户如果遇到连接反复断开，优先检查服务传输方式、后端日志和系统日志。
- 更新后如果界面仍显示旧状态，重启客户端和后端，再确认版本号。

## v0.0.6

发布日期：2026-06-28

v0.0.6 重点重建文档站、完善外观自定义、启用 Windows 便携包，并改善 Wiki、安装器配置和发布流程。

### 新增能力

| 模块 | 详细信息 |
| --- | --- |
| 文档站 | 新增多语言文档站，包含功能指南、安装指南、参考页、截图、Release 下载面板和字体子集生成。 |
| 外观自定义 | 新增背景图、主题色、全局外观效果层和颜色选择控件。 |
| Windows 发布 | 启用 Windows 便携版产物，方便不想安装的用户直接解压运行。 |

### 改进和修复

- 改善应用内 Wiki、文档导航、主页布局、顶部 Logo 和滚动条样式。
- 改进 Tauri 安装配置路径解析和 setup 存储逻辑。
- 重新整理 README、文档页、功能说明、`setup.toml` 参考和中英文安装说明。
- 修复安装指南链接、setup 页国际化、Wiki 显示、文档 source 行为、链接选中样式和站点样式回归。

## v0.0.5 及更早版本

早期版本主要围绕 Tauri 桌面端基础能力、配置页、调度器、更新器、远程画面和发布流程逐步建立。当前文档会优先覆盖最新稳定版本；如果你仍在使用旧版本，建议先升级到最新版本后再按当前文档排查。
