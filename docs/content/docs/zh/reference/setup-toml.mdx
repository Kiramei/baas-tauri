`setup.toml` 是 BAAS 后端安装和更新阶段使用的配置文件。Tauri 客户端的安装器会把常用选项做成图形界面，但当你需要排查更新源、MirrorC CDK、运行时路径或跳过更新时，仍然可能需要理解这个文件。

<Callout type="warn" title="不要公开 setup.toml">
  如果你填写了 MirrorC CDK、私有源或本机路径，不要把完整 `setup.toml` 直接发给陌生人或公开 Issue。
</Callout>

## 安装器步骤

旧后端安装器的核心步骤可以抽象为：

### 检查 Python 与运行时 [step]

确认本机或内置运行时可用，必要时下载或修补后端需要的 Python 环境。

### 准备 pip 与下载源 [step]

根据 `setup.toml` 中的源配置准备 pip，并在网络失败时按源列表重试。

### 克隆或更新后端源码 [step]

从 GitHub、镜像源或 MirrorC 获取 BAAS 后端代码，并根据 SHA 判断是否需要刷新。

### 安装 Python 依赖 [step]

同步后端运行依赖。依赖未变化时，安装器可能会跳过这一步以节省时间。

### 写入版本与路径状态 [step]

记录当前 BAAS 版本、C++ 组件版本、后端目录和运行时路径，供后续启动和更新复用。

### 启动后端服务 [step]

安装完成后启动后端进程，等待 Tauri 客户端完成本地连接和密钥认证。

当前 Tauri 安装器仍围绕这些动作组织，只是把目录选择、更新源、MirrorC CDK 和日志展示放进桌面界面。

## 常用 General 参数

| 参数 | 类型 | 作用 | 建议 |
| ---- | ---- | ---- | ---- |
| `mirrorc_cdk` | string | MirrorC 下载加速凭据 | 只在你购买或获得 CDK 后填写 |
| `current_BAAS_version` | string | 当前后端版本 | 通常自动维护 |
| `current_BAAS_Cpp_version` | string | 当前 C++ 组件版本 | 通常自动维护 |
| `get_remote_sha_method` | string | 获取远程 SHA 的方式 | GitHub 不通时切换到镜像 |
| `dev` | bool | 不从远程更新代码 | 本地开发或临时冻结版本时使用 |
| `refresh` | bool | 覆盖本地后端修改 | 会丢弃本地改动，谨慎使用 |
| `launch` | bool | 跳过安装步骤直接启动 | 已确认环境完整时使用 |
| `force_launch` | bool | 是否关闭已启动的旧进程 | 多实例排查时注意 |
| `debug` | bool | 更新后保留终端窗口 | 排查安装失败时有用 |
| `source_list` | list | PyPI 源重试列表 | 网络不稳定时调整 |
| `runtime_path` | string | 自定义 Python 运行时 | 只有理解后端环境时再改 |

## URL 与路径参数

| 参数 | 说明 |
| ---- | ---- |
| `REPO_URL_HTTP` | 后端源码获取地址，可切换 GitHub、Gitee、GitCode 或其他镜像 |
| `GET_PIP_URL` | `get-pip.py` 下载地址 |
| `GET_UPX_URL` | UPX 下载地址 |
| `GET_ENV_PATCH_URL` | 环境补丁下载地址 |
| `GET_PYTHON_URL` | Python 运行时下载地址 |
| `BAAS_ROOT_PATH` | 后端安装根目录，修改时必须使用绝对路径 |
| `TMP_PATH` | 临时文件目录 |
| `TOOL_KIT_PATH` | 工具目录 |

## MirrorC CDK

MirrorC 是第三方分发和下载加速服务。填写 CDK 后，BAAS 后端更新可以走 MirrorC 源；不填写也可以继续使用默认更新源，只是网络质量取决于你所在环境。

```toml
[General]
mirrorc_cdk = "your-cdk"
```

## 何时手动修改

| 场景 | 可以修改 |
| ---- | -------- |
| GitHub 访问失败 | `REPO_URL_HTTP`、`get_remote_sha_method` |
| PyPI 下载慢 | `source_list` |
| 想临时跳过更新 | `launch = true` 或 `dev = true` |
| 调试安装失败 | `debug = true` |
| 使用 MirrorC | `mirrorc_cdk` |

如果你只是普通使用 BAAS Tauri，优先使用安装器里的“高级设置”和“更新源”控件，不要直接编辑 `setup.toml`。
