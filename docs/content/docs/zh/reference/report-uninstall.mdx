反馈问题时，目标不是“描述感觉”，而是让维护者能复现或定位问题发生在哪一层：Tauri 客户端、后端服务、ADB/模拟器、截图识别、具体任务、调度或更新源。

## 反馈前检查

提交 Issue、群内反馈或向维护者求助前，先确认：

| 检查项 | 说明 |
| ------ | ---- |
| 版本 | 客户端和后端是否已经更新到最新版 |
| 配置 | 模拟器、服务器、截图方式、控制方式是否符合文档 |
| 复现 | 是否每次都发生，还是偶发 |
| 日志 | 是否保留完整日志，而不是只截最后一行 |
| 截图 | 是否包含游戏画面、配置弹窗和 BAAS 日志 |
| 风险 | 是否已停止会消耗资源的任务 |

## 按问题类型准备材料

| 问题类型 | 必须提供 |
| -------- | -------- |
| 卡在某页面不动 | 1280x720 游戏画面、BAAS 日志、当前任务名 |
| 推图走格子卡住 | 从开始推图到卡住的录屏，游戏和日志同屏 |
| 配置了但没执行 | 对应配置页截图、调度页截图、日志 |
| 没配置却执行了 | 当前配置档、任务队列、调度设置、日志 |
| ADB 无法连接 | 模拟器类型、ADB 端口、检测结果、后端日志 |
| 更新失败 | 更新源、SHA 测试结果、安装器日志 |

<Callout type="info" title="截图建议">
  游戏画面尽量使用无损 PNG。录屏时让游戏窗口和 BAAS 日志同框，避免只录游戏或只录日志。
</Callout>

## 找到配置文件

后端配置通常位于后端安装目录的 `config` 目录中。每个子目录对应一个配置档，目录内 `config.json` 的 `name` 字段与界面显示名对应。

当前 Tauri 客户端更推荐使用配置档导出功能：导出 `.zip` 后再按需要提供给维护者。公开反馈前检查里面是否包含账号、CDK、本地路径或其他敏感信息。

## 隐私和安全

不要公开：

- BAAS 密钥。
- MirrorC CDK。
- 私有仓库、代理或加速源。
- 个人本地路径中不想公开的用户名。
- 游戏账号敏感信息。

如果维护者需要配置档，优先私下发送，并先说明问题发生的任务和复现步骤。

## 卸载

BAAS 由两个部分组成：

| 部分 | 卸载方式 |
| ---- | -------- |
| Tauri 客户端 | 使用系统应用卸载入口，或删除便携版目录 |
| BAAS 后端目录 | 停止后端和 ADB 进程后删除后端安装目录 |

如果后端目录无法删除：

1. 关闭 BAAS Tauri。
2. 打开任务管理器。
3. 结束残留的 `python.exe`、`adb.exe`、模拟器相关进程。
4. 再删除后端安装目录。

如果要迁移到另一台电脑，优先使用配置档导出/导入。直接复制整个后端目录也可能可行，但会携带本机路径、运行时和缓存，不如导出配置档干净。
