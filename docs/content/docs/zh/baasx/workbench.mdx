## 认识界面

运行 `baasx`（不带单次命令）进入交互工作台。顶部是白色 **BAASX** 标题、当前配置档、连接状态和调度摘要；中间是当前页面；底部是命令输入栏和快捷提示。

切换页面时页头保持相同布局。非总览页面的导航与内容之间保留一行间隔。较矮或较窄的终端会压缩页头并换行显示列表详情，终端高度很小时进一步缩为两行页头。

| 页面   | 打开方法            | 主要内容                                 |
| ------ | ------------------- | ---------------------------------------- |
| 总览   | `/home`             | 运行与调度摘要、当前任务和操作反馈       |
| 任务   | `/tasks`、Ctrl+T    | 后端实际可用的任务及一次性任务入口       |
| 调度   | `/scheduler`        | 启用状态、下次执行时间、优先级和调度字段 |
| 配置档 | `/profiles`、Ctrl+P | 当前后端的配置档，选择目标               |
| 日志   | `/logs`、Ctrl+L     | 当前运行的实时日志和历史尾部             |
| 配置   | `/config`           | 分类与类型化编辑器                       |
| 指令包 | `/packs`            | 内置与用户 JSON 指令包                   |

Shift+Tab 循环切换页面，也可以直接点击导航。顶部只显示必要的连接状态，不用根据 socket 或 `.lock` 路径判断是否正常。

## 输入命令与查看帮助

在底部输入 `/` 打开命令候选，继续输入筛选，用 Tab 补全。`/help` 或 `?` 打开帮助页，展示命令作用、参数和示例。帮助内容过长时用滚轮、PageUp / PageDown 或分页按钮查看。

常用流程：

```text
/profiles
/config
/tasks
/scheduler
/start
/logs
```

这些是依次执行的交互命令，不是复制到输入框的一段脚本。执行 `/start` 前先确认目标配置档和已启用任务。完整列表见[命令参考](./cli)。

## 键盘操作

| 按键                     | 作用                                                     |
| ------------------------ | -------------------------------------------------------- |
| ↑ / ↓                    | 在当前列表移动；输入栏的历史操作随当前焦点和界面状态变化 |
| Enter                    | 打开条目、提交输入，或确认当前选中的操作                 |
| Esc                      | 返回上一级、取消当前弹窗或编辑；安装时取消运行中的安装   |
| Shift+Tab                | 切换工作台页面                                           |
| Tab                      | 命令补全                                                 |
| Ctrl+T / Ctrl+P / Ctrl+L | 打开任务 / 配置档 / 日志                                 |
| Ctrl+R                   | 重载工作台                                               |
| Ctrl+A / Ctrl+E          | 输入栏移动到行首 / 行尾                                  |
| Ctrl+U / Ctrl+K          | 删除光标前 / 光标后的输入                                |
| PageUp / PageDown        | 当前可滚动区域翻页                                       |
| Ctrl+C                   | 取消当前前台操作、等待或输入；空闲且输入为空时退出       |
| Ctrl+D                   | 退出                                                     |

编辑器会显示自己的按键提示。例如优先级列表用 ← / → 调整顺序、Space 添加或移除、Ctrl+S 保存。不要把输入栏的编辑按键与配置列表操作混用，具体以当前区域底部提示为准。

## 鼠标与确认

可以点击导航、列表项、编辑器按钮和确认按钮；滚轮滚动所在列表、日志或安装步骤。较长标签与末行日志会横向滚动显示。

普通单任务运行、停止、配置修改和有修改步骤的指令包会先给出确认。默认选中 Yes，Enter 提交；`n` 或方向键切换取消，Esc 取消。先阅读确认中的目标配置档和动作。

**启动调度 `/start` 直接执行。** `--read-only` 和 `--dry-run` 仍生效，已有运行或无有效配置档等条件仍会阻止提交。

## 日志分栏与跟随

执行任务后自动显示实时日志。终端宽度达到 **110 列**时，工作区可以在右侧并排显示日志。

1. 打开任务或开始一次运行，让日志区域显示。
2. 把鼠标移到工作区与日志之间的竖线。
3. 按住左键左右拖动，改变左右区域宽度。
4. 松开后继续操作；调整窗口大小时保留分栏比例。

两侧都有最小宽度，不能把任意一侧拖到不可用。窄终端使用独立 `/logs` 页面。向上滚动暂停自动跟随，回到最底部恢复；检查旧日志时不必与持续刷新的输出争抢滚动位置。

连接成功只能证明会话建立，不能证明任务完成。应结合运行状态、关联的日志和最终结果判断，脚本可用 `--wait` / `--follow` 等待相同运行编号，详见[调度与任务](./scheduler)。

## 重载工作台

输入 `/reload` 或按 Ctrl+R：

1. 清除页面、输入和未保存编辑草稿。
2. 重新读取偏好与指令包。
3. 恢复服务连接并返回总览。

这相当于客户端“重载”的工作台操作。**本地后端与正在执行的任务继续运行**，因此它不能代替 `/stop`，也不会升级程序。刚安装或修改指令包后，可以用它让当前工作台读取新文件。

系统终端的 `baasx reload` 含义不同：只在新命令进程中读取指令包，不能刷新另一个已打开的工作台。

## 语言、颜色和动画

`/language` 切换语言；启动时用 `--lang zh` 或 `--lang en`。还支持日语、韩语、德语、法语和俄语。切换显示语言不会改变后端枚举值或真实任务 ID。

运行指示采用青色星芒、文字扫光和呼吸效果，等待与提示使用蓝紫色。可在系统终端设置减少动画：

```sh
BAAS_REDUCED_MOTION=1 baasx
```

PowerShell：

```powershell
$env:BAAS_REDUCED_MOTION = "1"
.\baasx.exe
```

`--no-color` 或 `NO_COLOR` 关闭颜色。重定向输出及 `TERM=dumb` 场景会关闭动画。网页演示也提供暂停，并尊重系统“减少动态效果”偏好。

## 安装进度怎么读

安装和更新以步骤列表展示，每项包含状态、耗时和可用的下载进度。正在运行的步骤展开末尾日志，已完成步骤折叠；点击完成项可以重新查看日志。

滚轮和翻页键只移动视图，不改变执行顺序。运行中 Esc 取消；完成后 Esc 返回工作台。若失败，记录具体失败步骤与最后错误，按[故障排查](./troubleshooting)处理。
