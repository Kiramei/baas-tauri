低风险维护任务包括邮箱、奖励、社团体力、pass 奖励；中风险任务包括好友清理、MomoTalk、制造和推送；反和谐属于区服相关操作，不确定时不要执行。

## 反和谐

反和谐只面向国服相关场景。旧文档说明 BAAS 在反和谐前后通常都能运行，但立绘和部分文字可能变化，因此仍建议在执行前停止调度并确认当前区服。

执行前确认：

- 已经打开并连接目标模拟器。
- 当前配置档确实是国服。
- 没有正在运行的任务。
- 执行后重新进入游戏确认资源状态。

## 推送 JSON 格式

如果使用自定义 JSON 推送地址，后端会发送类似下面的内容：

```json
{
  "title": "Baas Error",
  "desp": "error..."
}
```

自建接收端应能处理这个结构；如果只使用 Server 酱，填写对应 SendKey 即可。
