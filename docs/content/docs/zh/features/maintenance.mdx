维护任务可能删除好友、对外发送日志或修改游戏资源，并非不战斗就没有风险。这些编辑器使用[自动保存](../guide/configuration)；保存设置和执行任务是两回事。

## 好友清理

<img
  className="baas-screenshot"
  src="/media/desktop/zh/config-whitelist.png"
  alt="新版好友清理编辑器：三个筛选条件和好友码白名单"
/>

**删除警告**：核验的默认后端 `module/friend.py` 会删除所有不在 `clear_friend_white_list` 中的好友，**未读取下面三个新增筛选字段**。新安装 Android 客户端下载的后端也已确认存在同样限制。不要依靠筛选框保护好友；除非确实要进行这种删除，否则不要在空白名单下运行清理。

| 界面筛选条件       | 保存字段                                     | 客户端校验         |
| ------------------ | -------------------------------------------- | ------------------ |
| 等级上限           | `clear_friend_level_limit`                   | 不小于 `-1` 的整数 |
| 距上次登录天数     | `clear_friend_last_login_time_days`          | 不小于 `-1` 的整数 |
| 上次总力战排名限制 | `clear_friend_last_total_assault_rank_limit` | 不小于 `-1` 的整数 |

界面约定 `-1` 表示关闭某个条件，但不能据此认定实际后端已经实现筛选，更不能假定多个条件按“并且”或“或者”生效。任一阈值为空或为小数，会阻止该分类草稿提交，也包括同一草稿中的白名单修改。

### 编辑白名单

输入好友码后点击添加，或完成输入法组词后按 Enter。首尾空白会去除，重复项会拒绝。校验根据配置档区服，而非界面语言：

| 区服类别      | 当前客户端接受的格式                 |
| ------------- | ------------------------------------ |
| 国服，含 B 服 | 7 位小写 ASCII 字母或数字            |
| 国际服        | 8 位大写 ASCII 字母                  |
| 日服          | 8 个字符；界面没有额外的字符模式校验 |

添加后显示为标签。标签上的删除图标只移除白名单保护，不会立即删除游戏好友；下次清理可能删除这个好友。列表保存为 `clear_friend_white_list`。启用清理前务必对照实际账号核对好友码。

## 推送通知

<img
  className="baas-screenshot"
  src="/media/desktop/zh/config-push.png"
  alt="推送编辑器：错误和完成开关、JSON 接收地址及 Server 酱密钥"
/>

| 控件               | 配置含义                                          |
| ------------------ | ------------------------------------------------- |
| 发生错误后推送     | `push_after_error`：后端报告错误时发送错误内容    |
| 所有任务完成后推送 | `push_after_completion`：本次运行完成后发送       |
| JSON 推送          | `push_json`：接收端 URL，**不是** JSON 文本       |
| Server 酱          | `push_serverchan`：填写 SendKey，不是完整接口地址 |

这两个文本框不隐藏密钥，前端也不验证网络是否可达。截图、共享配置和公开日志中不要暴露密钥或带签名的 URL。地址或密钥留空会关闭对应渠道；两者都非空时可以同时推送。

核验的后端以 `Content-Type: application/json` 发送 POST。错误内容示例：

```json
{
  "title": "Baas Error",
  "desp": "error..."
}
```

完成时标题为 `Baas Completed`，描述为 `all activities finished`。后端按 HTTP 200 判断成功，请求失败会记入日志；保存地址并非发送测试通知。Server 酱接口为 `https://sctapi.ftqq.com/{SendKey}.send`。后端另有高级飞书字段，但当前编辑器没有飞书控件。

## 反和谐

<img
  className="baas-screenshot"
  src="/media/desktop/zh/config-other.png"
  alt="其他分类中的一次性反和谐执行命令"
/>

“其他”分类只有反和谐的**执行**命令，不是长期启用开关。点击会立即提交 `start_fhx` 并返回首页，不要用它测试配置能否保存。

这是针对国服游戏资源的操作。执行前停止调度，核对配置档实际对应的包名和区服，保留必要游戏数据并确认后端支持。正常自动化不要求执行反和谐，它也不是识别失败的通用修复方式。执行后重新进入游戏核对资源状态；后续游戏更新还可能改变该状态。

## 其他维护任务

邮箱、每日奖励、社团体力、通行证奖励和 MomoTalk 在任务列表中选择，不是上述三个分类里的额外控件。任务时间与依赖见[任务调度](../guide/scheduler)。领取奖励也会改变账号状态，MomoTalk 可能推进对话；首次运行应监督并查看日志，不要默认所有维护任务都适合无人值守。
