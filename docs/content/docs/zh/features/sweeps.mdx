## 扫荡细节

  className="baas-screenshot"

| 项目                  | 影响             |
| --------------------- | ---------------- |
| 普通/困难图每日扫荡   | 消耗体力和次数   |
| 悬赏通缉 / 学院交流会 | 消耗对应票券     |
| 活动关卡扫荡          | 依赖当前活动识别 |
| 票券购买次数          | 会额外消耗资源   |

## 参数格式

| 类型       | 格式                       | 示例                             |
| ---------- | -------------------------- | -------------------------------- |
| 普通图扫荡 | `区域-关卡-次数`           | `15-3-3,20-3-max`                |
| 困难图扫荡 | `区域-关卡-次数`           | `15-1-3,16-3-max`                |
| 活动扫荡   | 关卡列表和次数列表分别填写 | 关卡 `9,10,11`，次数 `0.5,3,1/3` |

次数可以使用：

| 写法   | 含义                               |
| ------ | ---------------------------------- |
| 正整数 | 固定扫荡次数                       |
| `max`  | 当前体力能扫多少就扫多少           |
| 小数   | 使用当前体力的一部分，例如 `0.5`   |
| 分数   | 使用当前体力的一部分，例如 `1/3`   |
| `-1`   | 活动关卡中把体力平均分配给所选关卡 |

扫荡配置会消耗体力、扫荡次数和可能的购买资源。新配置先用小次数验证。
