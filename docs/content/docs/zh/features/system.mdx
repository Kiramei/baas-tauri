---
title: 系统设置
description: 设置分类、本地持久化、外观、应用内与全局快捷键、传输方式和系统日志操作。
---

从导航栏打开**设置**，桌面侧栏分为通用、外观、快捷键、连接与运行时、更新、日志；窄窗口使用分类选择器。Android 隐藏快捷键分类，保留其余五类。搜索用于定位设置项和分类。

大部分外观与偏好是**客户端全局设置**，不属于当前游戏配置档。修改即时生效并本地持久化（`uiSettings`，约 150 ms 批量落盘），切换配置档不会得到独立主题或解码器。任务配置使用另一套[配置历史](../guide/configuration)。

自动保存也有例外：配置档弹窗、全局快捷键弹窗、远程高级设置需要明确保存；Mirror 酱密钥需要验证。更新选项影响共用后端设置，切换传输方式会重新连接后端。

## 通用

<img
  className="baas-screenshot"
  src="/media/desktop/zh/settings-general.webp"
  alt="新版通用设置：语言、低性能模式和桌面偏好"
/>

| 控件           | 影响与保存项                                                                               |
| -------------- | ------------------------------------------------------------------------------------------ |
| 语言           | 英、中、日、韩、德、俄、法七种；`lang`。不是游戏区服或文档语言                             |
| 低性能模式     | 减少界面动画和视觉效果；`lowPerformanceMode`。不会修改游戏画质，也不代表已测得固定加速     |
| 系统通知       | 原生桌面任务/服务通知；`enableSystemNotifications`。操作系统权限仍可能阻止显示             |
| 最小化到托盘   | 最小化时隐藏窗口到托盘并保持后台运行；`minimizeToTray`。不是退出，也不保证系统休眠期间运行 |
| 安装后自动进入 | 桌面安装成功后进入客户端；`autoEnterAfterInstall`。不是开机启动注册或调度自动运行          |

最后三项属于桌面原生控件。Android 不显示桌面通知、托盘、安装器组；WebUI 没有原生桌面集成。通用页还提供[插件入口](./plugins)；WebUI 的登录与 Key 重置见[浏览器部署](../guide/webui#登录与重置-key)。

## 外观

<img
  className="baas-screenshot"
  src="/media/desktop/zh/settings-appearance.webp"
  alt="新版外观设置：分段主题、强调色、背景和显示控制"
/>

| 控件       | 操作                                                                                |
| ---------- | ----------------------------------------------------------------------------------- |
| 主题       | 浅色、深色、跟随系统；`theme`。系统模式跟随 OS                                    |
| 主题色     | 颜色选择器、色相/区域、受支持时的取色器、八个预设、十六进制输入、重置；`themeColor` |
| 背景图片   | 选择或移除本地保存的图片；`backgroundImageBase64`                                   |
| 背景透明度 | 0–60%，步长 1%；`backgroundImageOpacity`。零只隐藏显示，不删除存储字节              |
| 界面缩放   | 50–150%，每档相差十个百分点；`zoomScale`。不修改游戏/设备分辨率                     |
| 资源显示   | 显示/隐藏首页资源条；`assetsDisplay`。隐藏不会停止后端采集                          |
| BAComet    | 切换可选视觉效果；`enableBAComet`                                                   |

<img
  className="baas-screenshot"
  src="/media/desktop/zh/details-theme-color.webp"
  alt="主题色选择器与预设"
/>

外层十六进制输入必须是 `#RRGGBB`，失焦或 Enter 提交。非法文本提示错误并恢复已保存颜色。重置恢复 `#1a1c1f`，不是清空全部外观设置；选择器和预设会直接生效，取色器是否可用取决于宿主。

背景支持 PNG、JPG/JPEG、WebP、GIF，最大 **5 MiB**。原生客户端读取选择的文件，WebUI 使用浏览器文件选择器；取消不修改图片。图片字节嵌入本地设置，不会作为公开文档资源上传。无背景时移除按钮禁用；有背景时点击立即移除，没有二次确认。

Android 首次迁移将初始缩放设为 80%，之后仍可通过界面缩放控件调整。

### 应用内快捷键

这些只在应用窗口内工作，不是操作系统全局脚本触发键。点击该行录制图标，按下组合并等待结束；只按修饰键不完整，Escape 取消。清除图标保存空绑定，禁用该动作。合法录制即时保存，没有保存弹窗。

| 动作与 ID             | Windows/Linux 默认 | macOS 默认  |
| --------------------- | ------------------ | ----------- |
| 撤销，`undo`          | Ctrl+Z             | Cmd+Z       |
| 重做，`redo`          | Ctrl+Y             | Cmd+Shift+Z |
| 设置，`settings`      | Ctrl+,             | Cmd+,       |
| 侧栏，`sidebar`       | Ctrl+Shift+S       | Cmd+Shift+S |
| 后退，`back`          | Alt+Left           | Alt+Left    |
| 前进，`forward`       | Alt+Right          | Alt+Right   |
| 放大，`zoomIn`        | Ctrl++             | Cmd++       |
| 缩小，`zoomOut`       | Ctrl+-             | Cmd+-       |
| 重置缩放，`resetZoom` | Ctrl+0             | Cmd+0       |
| 全屏，`fullscreen`    | F11                | F11         |

覆盖值保存在 `applicationShortcuts`。非法组合、重复的应用绑定、已启用全局配置档键冲突，以及保留的原生编辑键/Escape 都会拒绝；拒绝后保留上一次合法绑定。录制期间其他行及重置操作处于非活动状态。

<img
  className="baas-screenshot"
  src="/media/desktop/zh/details-shortcut-conflict.webp"
  alt="将保留的复制组合录入撤销时提示冲突，原绑定保持不变"
/>

全部重置只恢复应用默认，不修改全局配置档键；若已启用全局键与默认组合冲突，重置也可能被阻止。原生剪切、复制、粘贴、全选、删除及 Escape 只是参考行，不可在此重绑。动作还受上下文和平台限制：配置页撤销针对配置历史，不是撤销游戏任务；弹窗、文本编辑或不可用的窗口动作可能优先处理。

### 全局配置档快捷键

<img
  className="baas-screenshot"
  src="/media/desktop/zh/details-global-shortcuts.webp"
  alt="独立全局配置档快捷键弹窗：搜索、取消和保存"
/>

原生桌面端有配置档运行组。“编辑”打开共用全局快捷键弹窗，首页键盘图标也能进入。每行控制对应名字配置档的调度启停，即使焦点在其他应用。搜索匹配配置名或按键文本，不会丢弃未显示的草稿行。

与应用内录制不同，这里的修改需点击**保存**才提交，取消或关闭会丢弃草稿。留空禁用绑定。格式、重复和系统注册拒绝都需要处理；弹窗报错时不能认定键已注册成功。从设置进入时还会检查应用内绑定冲突。录制时暂停快捷键处理，避免录制本身启动任务。Android/WebUI 不提供桌面操作系统全局配置档快捷键。

## 连接与运行时

<img
  className="baas-screenshot"
  src="/media/desktop/zh/settings-runtime.webp"
  alt="连接与运行时：后端传输、预览解码和加密预览"
/>

| 控件         | 选项与作用范围                                                            |
| ------------ | ------------------------------------------------------------------------- |
| 后端传输方式 | 原生桌面提供 `shm`、`websocket`；Windows/Linux 还可使用 `pipe`                |
| 预览解码器   | `mse`、`broadway`、`tinyh264`、`webcodecs`；`remoteSettings.streamPlayer` |
| 安全流模式   | `remoteSettings.enableSafeStream`；加密 WebSocket 预览，不是画质模式      |

传输用于**客户端与后端**通信，和 ADB、游戏截图方式独立。切换会关闭业务连接、启动托管传输并重新同步，需等待恢复，避免在任务中切换。Windows/Linux 保留明确选择的 pipe 或 WebSocket，默认优先使用可用的共享内存，否则回退 pipe；macOS 默认共享内存，也可明确选择 WebSocket。Android 使用 pipe 或 WebSocket，WebUI 固定为 WebSocket。不支持的旧存储值会归一化。

桌面解码器和加密流控件不控制 Android 原生 TextureView。桌面修改后关闭首页远程预览，再重新打开，以重建播放器连接。视频控制及高级设置现有限制见[首页运行](./home-runtime)，传输所有权见[架构](../reference/client-architecture)，测量范围见[性能](../reference/performance)。

## 日志

自动滚动开关（`scrollToEnd`）与首页向下箭头共用，控制任务日志，不是系统日志查看器独立的跟随末尾开关。

<img
  className="baas-screenshot"
  src="/media/desktop/zh/details-system-log-details.webp"
  alt="新版系统日志查看器：筛选生命周期记录并展开详情"
/>

打开系统日志，可查看 `tauri`、`python`、`frontend` 三类诊断。来源按钮数量对应采集快照；级别筛选支持全部、TRACE、DEBUG、INFO、WARNING、ERROR。搜索不区分大小写，覆盖来源、级别、目标、消息和详情；有详情的行可展开。

| 工具       | 精确作用范围                                             |
| ---------- | -------------------------------------------------------- |
| 刷新       | 重新采集快照，某来源失败时可显示警告，其他来源仍可能可用 |
| 复制、导出 | 只含**当前筛选结果**及格式化详情                         |
| 自动刷新   | 弹窗打开时每三秒采集                                     |
| 跟随末尾   | 滚动到最新显示行，与刷新独立                             |
| 清空       | 确认后清理前端、原生与后端系统日志，**不是只清理筛选行** |

合并查看器每次最多保留 4,000 条，前端内存缓冲为 1,500 条，长消息可能截断；导出不是无限量磁盘日志归档。原生导出使用保存弹窗，不可用时回退浏览器下载，剪贴板权限可能影响复制。

保留故障证据后再清空。日志可能含路径、设备/账号数据或密钥，分享前先筛选并脱敏。系统日志排查应用/服务，与[首页任务日志](./home-runtime)的导出不同。
