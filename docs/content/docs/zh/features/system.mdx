---

系统设置影响 Tauri 客户端体验，不直接修改单个游戏任务策略。

<img
  className="baas-screenshot"
  src="/cn/settings-interface-preferences.png"
  alt="设置页界面区域，包含背景图、语言、UI 缩放、远程模拟器解码器、日志滚动、资产信息、BAComet 和低性能模式"
/>

| 设置             | 作用                       |
| ---------------- | -------------------------- |
| 主题 / 主题色    | 调整客户端视觉风格         |
| 背景图 / 透明度  | 个性化背景                 |
| 语言             | 切换应用 UI 语言           |
| UI 缩放          | 调整界面大小               |
| 远程模拟器解码器 | 处理黑屏、卡顿或兼容性问题 |
| 低性能模式       | 减少动画和开销             |
