title: 配置档
description: 配置档创建、复制、导入、导出、删除和命名建议。
---

配置档是 BAAS 的运行边界。区服、ADB 端口、模拟器路径、脚本参数、任务配置和调度状态都归属于当前配置档。多账号、多区服或多开模拟器时，优先创建多个配置档。

<img
  className="baas-screenshot"
  src="/cn/profile-actions-menu.png"
  alt="配置档菜单，包含编辑、复制配置、导出配置和删除"
/>

| 操作     | 用途                         | 注意                         |
| -------- | ---------------------------- | ---------------------------- |
| 编辑     | 修改配置档名称               | 名称建议包含区服和模拟器实例 |
| 复制配置 | 基于当前配置创建相似账号配置 | 复制后要重新检查 ADB 端口    |
| 导出配置 | 打包为 `.zip` 备份或反馈问题 | 不要公开包含隐私信息的配置   |
| 删除     | 删除当前配置档               | 最后一个配置档不能删除       |

## 新增与导入

<img
  className="baas-screenshot"
  src="/cn/profile-create-import-dialog.png"
  alt="新增配置弹窗，支持导入配置压缩包、填写配置名和选择服务器"
/>

配置名建议能直接区分账号、区服和模拟器实例，例如 `Bilibili-MuMu-1`、`Global-LD-2`、`JP-PC`。导入配置前需要客户端已连接并认证后端。

### 新增配置 [step]

点击新增配置，填写能区分账号、区服和模拟器实例的名称。

### 选择区服 [step]

选择与实际游戏客户端一致的服务器，避免后续任务使用错误的入口和识别资源。

### 设置 ADB [step]

配置 ADB IP、端口和模拟器实例，确认当前配置档连接的是正确设备。

### 配置任务 [step]

进入功能配置和调度页，先配置并验证低风险任务，再逐步扩展到扫荡、商店和战斗类任务。

### 导出备份 [step]

配置稳定后导出 `.zip` 备份。迁移电脑、复现问题或分享配置时，先检查里面是否包含隐私信息。
