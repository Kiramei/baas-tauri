配置档持有区服、设备、任务设置和调度状态，不是客户端外观或共用后端更新设置的独立副本。执行消费或删除任务前，先核对当前选中的名字。

## 选择与排列

桌面端在侧栏显示配置档，窄窗口/Android 使用横向条。点击选择；长名可能截断，悬停/聚焦显示操作位置。运行指示属于对应配置档，不一定是当前选中的档。

桌面纵向、横条横向拖动可调整顺序，保存在本机 `tabOrder`，不是任务优先级或导出的账号排列。切换选择本身不会停止另一档调度；Android 因共享游戏显示还会限制冲突运行。

点击省略号菜单、右键配置档，或聚焦后使用菜单键/Shift+F10。菜单可用上下/Home/End 导航，Escape/Tab 关闭并返回焦点。

## 新建

点击添加配置图标，弹窗会提出未使用的默认名。输入有辨识度的名字并选择游戏区服；“创建”是明确提交，不是自动保存。

<img
  className="baas-screenshot"
  src="/media/desktop/zh/details-profile-create.png"
  alt="新版新建弹窗：导入压缩包、名称和必选区服"
/>

名称首尾空白会去除，空名、重名和未选择区服会拒绝。去空白后的名字按精确匹配比较，不建议只用大小写区分账号。失败保留弹窗和错误；提交/导入中禁用重复操作，取消或关闭丢弃弹窗修改。

后端创建并同步后，客户端选择新档。**新配置可能继承已启用的默认任务**，启动前检查/停止调度，并设置设备、购买、扫荡、战斗和好友。桌面端核对[区服/ADB](./server)、[模拟器](./emulator)、[脚本](./script)；Android 核对[地区包与 Shizuku](../guide/android)。

## 编辑与复制

<img
  className="baas-screenshot"
  src="/media/desktop/zh/details-profile-edit.png"
  alt="编辑配置弹窗：可改名称，游戏区服锁定"
/>

编辑用于改名，校验首尾空白与重名，需点击保存。区服不可编辑，需要另一游戏区服/包时新建配置。改名保留配置 ID，不是创建新账号，也不清空全部任务状态。

**复制配置会立即执行**，没有另一个名称/选项弹窗；核验后端复制配置目录，并使用唯一的 `_copy`、`_copy2` 等后缀命名，同步后客户端选中它。副本不是新的模拟器实例。运行前核对复制后的设备序列号、实例号、任务和敏感推送设置，不要认定复制的启用状态与时间天然安全。

## 导出与导入

导出配置向后端请求该档压缩包并保存为 `.zip`，原生端使用保存弹窗，取消文件选择不会移除配置。核验后端会包含该配置目录下所有文件；它不是完整后端、已安装游戏、客户端 UI 设置或游戏账号/会话备份。

压缩包可能包含私有配置，例如地址、推送密钥、好友码和设备路径，分享前检查；导出不等于自动脱敏。

**同名替换警告**：核验导入器创建新 ID 后，会删除与导入 `name` 同名的已有配置目录，界面没有额外覆盖确认。导入前停止受影响调度并导出当前数据；若要保留为独立配置而非替换，应有意识地修改压缩包内的配置名称。

新建弹窗和应用文件动作中可以导入压缩包。ZIP 根目录或一个共同顶层目录下，需有合法 `config.json` 且 `name` 非空。后端拒绝非法 ZIP/JSON 和不安全路径，并补齐受支持默认字段，但这不意味着可以信任陌生压缩包。

选择一个 `.zip`，等待后端校验/同步，再检查新选中的配置档。需要连接并完成身份验证；文件名或成功提示不代表游戏设备已连通。

桌面/WebUI 也接受把 ZIP 拖到应用上，非 ZIP 不会导入。多个 ZIP 依次处理，后一个失败不会回滚已导入的前一个；导入层阻止同时启动另一批，等待结束后再操作。原生拖放取决于宿主支持。

## 删除

<img
  className="baas-screenshot"
  src="/media/desktop/zh/details-profile-delete-confirmation.png"
  alt="新版带配置名的删除确认，本次截图未实际删除配置"
/>

删除先弹出带名字的确认；取消、关闭或点击外部都会保留配置。中键点击配置档也会打开删除确认，不是普通选择快捷方式。

最后一个配置档禁止删除。确认删除其他档会发送 `remove_config` 移除对应后端配置，不能靠配置撤销恢复；先导出必要数据并停止该档。删除当前档后会选择邻近剩余档。删除配置不是删除游戏账号，但丢失设置仍属破坏性操作。

启停和日志见[首页运行](./home-runtime)，任务开关与时间见[调度](../guide/scheduler)。
