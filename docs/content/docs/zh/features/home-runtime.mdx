主页是当前配置档的控制台。这里显示任务运行状态、下一个任务、队列、日志、远程模拟器画面和快捷操作。

<img
  className="baas-screenshot"
  src="/cn/home-dark-logs.png"
  alt="主页运行控制台，显示当前任务、下一个任务、队列、日志和启动停止按钮"
/>

| 区域       | 作用                       | 排查方向                       |
| ---------- | -------------------------- | ------------------------------ |
| 执行中任务 | 后端当前正在运行的任务     | 卡住时先看日志是否继续输出     |
| 下一个任务 | 调度器准备执行的下一项任务 | 不符合预期时检查调度启用状态   |
| 队列       | 已排队等待的任务           | 队列为空通常表示没有可执行任务 |
| 启动/停止  | 控制当前配置档调度器       | 停止后不会继续触发调度         |
| 导出日志   | 导出当前配置档日志         | 反馈问题时优先提供             |

## 远程画面

<img
  className="baas-screenshot"
  src="/cn/home-dark-remote-display.png"
  alt="主页开启远程模拟器缩略画面后，日志区域旁显示模拟器画面"
/>

远程画面适合观察脚本停在哪个页面，但它不是任务成功的充分条件。任务是否稳定仍取决于区服、ADB、截图方式、控制方式和功能配置。

<Callout type="warn" title="首次运行建议">
  第一次运行时只启用一个低风险任务。确认日志、远程画面和资源变化都正常后，再逐步加入扫荡、商店、制造、竞技场等高影响任务。
</Callout>
