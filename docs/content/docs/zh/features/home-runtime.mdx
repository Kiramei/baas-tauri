## 启停与队列

| 控件或状态   | 含义                                                   |
| ------------ | ------------------------------------------------------ |
| 启动         | 向此档发送 `start_scheduler`，按启用任务及当前设置运行 |
| 停止         | 向此档发送 `stop_scheduler`，不是回滚已发生的游戏操作  |
| 执行中任务   | 后端 `current_task`，不同于调度器是否启用              |
| 后续任务链   | 后端 `waiting_tasks` 的队列顺序，不是所有未来计划任务  |
| 任务概览图标 | 用编号弹层展示队列，紧凑行截断时也可查看               |

调度器可能正在等待，运行状态为真但没有当前任务。空队列不能证明全部任务关闭，也不能证明之后没有到期任务；结合按钮状态和[调度时间](../guide/scheduler)判断。

停止是请求，切换设备、替换文件或再执行高影响任务前，确认后端状态和日志。它不能撤销购买、删好友、领资源或已进入的关卡；关闭预览也不是桌面调度停止命令。

## 资源与任务日志

可选资源条显示后端上报的体力、货币、制造材料与通行证信息。尚未收到的值可能为空/不可用，显示值不是每帧重新 OCR 的证明。外观中的 `assetsDisplay` 可以隐藏资源条，不删除账号数据；本次截图使用关闭状态。

日志工作区显示当前档已收到的任务日志缓冲，包含时间、级别、消息，非空时显示数量。向下箭头切换自动滚动（`scrollToEnd`，与设置 → 日志共用）。关闭后可阅读旧行，不会暂停接收日志或停止任务。

导出日志把已接收的当前档缓冲保存为 `logs-{配置ID}-{时间}.txt`。原生端显示保存弹窗，WebUI 通过浏览器下载；不是完整磁盘归档，也不含其他所有档。首页空白不代表没有原生/启动错误，[系统日志](./system#日志)是另一套诊断查看器和导出。分享前核对密钥及账号/设备信息。

## 桌面远程预览

摄像头图标切换与当前档设备的连接，不会因此启动调度。先确认 [ADB](./server)；选错配置档可能显示并控制错误环境。

<img
  className="baas-screenshot"
  src="/media/desktop/zh/details-remote-preview.png"
  alt="桌面真实预览正在镜像 MuMu 内的文档演示 Android 应用，不是游戏任务完成截图"

等待实际画面，不只看连接状态。点击已连通缩略图进入放大视图，关闭弹窗会把同一播放器放回缩略图；首页摄像头关闭/重开才销毁并重建连接。反复连接中、黑屏或画面冻结应排查解码器、设备和服务，不要反复启动调度。

结束后明确关闭摄像头；只切换可见页面/配置档，不能可靠地关闭缓存首页持有的播放器。

### 设备控制

放大视图接受指针/触摸手势，并有可展开工具栏。控件发送真实设备输入，自动化运行时避免同时操作。

| 图标                 | 影响                                   |
| -------------------- | -------------------------------------- |
| 电源                 | 设备电源键事件，不只是隐藏预览         |
| 音量减/加            | 调整设备音量                           |
| 返回、主页、应用切换 | Android 导航按键                       |
| 相机                 | 将已解码画面保存 PNG，没有画面时不保存 |
| 键盘开关             | 开启/关闭向设备转发受支持的键盘事件    |

桌面视图可交互，与 Android **只读**嵌入预览不同；进入放大桌面视图后，不能认定点击画面只是查看。

### 高级设置

<img
  className="baas-screenshot"
  src="/media/desktop/zh/details-remote-advanced.png"
  alt="新版远控高级设置：剪贴板、尺寸、帧率、I 帧、码率和状态"
/>

| 控件                   | 保存项与默认值                                                    |
| ---------------------- | ----------------------------------------------------------------- |
| 剪贴板文本、设置剪贴板 | 把文本发到设备，不只是本地备注                                    |
| 获取剪贴板             | 请求设备剪贴板，填入文本框，并尝试复制到主机剪贴板                |
| 第一个尺寸字段         | `remoteSettings.maxWidth`，默认 `1280`                            |
| 第二个尺寸字段         | `remoteSettings.maxHeight`，默认 `720`                            |
| 最大帧率               | `remoteSettings.maxFPS`，默认 `60`                                |
| I 帧间隔               | 编码器的 `remoteSettings.iFrameRate`，默认 `10`，不是识别截图间隔 |
| 比特率                 | 编码器的 `remoteSettings.bitRate`，默认 `7340032`                 |
| 显示状态               | `remoteSettings.showStatus`，显示流量及输入/丢失/解码帧率和平均值 |

**现有标签问题**：核验的中英文翻译把第一个尺寸字段写成“最大高度”，实际绑定 `maxWidth`；第二个写成“最大宽度”，实际绑定 `maxHeight`。排查尺寸时以此处字段关系为准。

数字输入使用整数解析，但没有完整有限数/范围校验；不要留空或用非法数探测后端上限。这些是请求给编码器的边界，不保证显示/游戏达到该 FPS，也不是性能提升实测。

剪贴板命令和显示状态直接生效；尺寸、帧率、I 帧和码率需要点击**保存并应用**。核验实现的即时应用路径读取旧设置快照，保存后应关闭首页预览再打开，按新值建立播放器；只关闭放大弹窗不会重建。

解码器和加密流在[连接与运行时](./system#连接与运行时)设置，也应重开预览使其生效。加密不能代替核对正确目标设备。
