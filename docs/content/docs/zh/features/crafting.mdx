打开**配置 → 制造**。全局设置决定制造次数与阶段数，
各阶段选项卡独立配置材料规则和节点优先级。
修改自动保存，制造调度任务需要单独启用。

## 全局控件

| 控件     | 值与效果                                                  | 导出字段                  |
| -------- | --------------------------------------------------------- | ------------------------- |
| 加速券   | 允许制造流程使用加速券，不会凭空增加票券                  | `use_acceleration_ticket` |
| 制造次数 | 整数 1–10，空值、小数或超范围草稿不保存，导出为数字字符串 | `createTime`              |
| 制造阶段 | 1、2 或 3，显示相应阶段选项卡                             | `create_phase`            |

减少阶段数会隐藏后续选项卡，不会删除已经保存的规则。
当前打开的阶段变为不可用时，编辑器返回全局。
更多阶段可能消耗额外材料；提高制造次数不代表空位、票券和材料一定足够。

## 各阶段材料选项

| 阶段   | 可用材料规则                                                                                                                                                               |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 一阶段 | 仅默认（`default`）                                                                                                                                                        |
| 二阶段 | 白（`primary`）、蓝（`normal`）、白蓝（`primary_normal`）、金（`advanced`）、紫（`superior`）、金紫（`advanced_superior`）、全部四档（`primary_normal_advanced_superior`） |
| 三阶段 | 金（`advanced`）、紫（`superior`）、金紫（`advanced_superior`）                                                                                                            |

对应字段为 `create_phase_1_select_item_rule`、
`create_phase_2_select_item_rule` 和 `create_phase_3_select_item_rule`。
一阶段没有提供所有颜色，三阶段也不能套用二阶段的完整选项集合。

## 节点优先级

各阶段分别使用 `createPriority_phase1`、`createPriority_phase2` 或
`createPriority_phase3`，选项取自游戏区服的后端数据。
点击添加打开可搜索节点列表，选择或取消选择节点，
使用移除图标删除条目。列表靠前的节点优先。

拖动把手可以排序。键盘排序时先聚焦把手，按 Space 或 Enter 拿起，
用上下方向键或 Home、End 移动，再按 Space 或 Enter 提交；
Escape 取消未完成的移动，鼠标释放则提交拖动。
移动预览尚未保存；提交后才更新配置，可用撤销恢复原顺序。
未知或旧格式节点标签会保留显示，不会悄悄丢弃。
空列表不保证后端完全不投入材料，应先确认实际任务行为再调度。

## 学生推荐

这个操作位于**二阶段**，需要先选择至少两个阶段。
选择学生会打开后端提供的推荐名称；选中一位学生后，
二阶段优先级列表会被替换为推荐节点在前、其他默认节点在后的顺序。
它不会合并任意自定义列表，也不保存一个永久“目标学生”字段。

<img
  className="baas-screenshot"
  src="/media/desktop/zh/conditional-craft-recommendation.png"
  alt="二阶段制造按学生名称查找推荐节点顺序"
/>

选中后选择器关闭，运行前先核对生成的节点顺序。
替换不符合预期时可使用配置撤销。这只是节点偏好，
不保证必定产出某种礼物，也不代表已经将礼物赠送给该学生。

## 首次执行

先使用较少次数，核对加速券许可、阶段数、每阶段材料范围和节点优先级，
再单独运行制造。检查材料扣除、选中节点、完成的制造位与任务日志。
只有明确接受额外材料消耗后，才提高阶段数。
