## 指定角色礼物

旧文档中的制造策略是：只有二级制造可以稳定指定角色喜欢的礼物。使用时先把制造阶数设为至少二级，再在二级制造配置中使用“按学生推荐”或“一键设置推荐优先级”。

| 目标 | 建议 |
| ---- | ---- |
| 获取指定角色礼物 | 使用二级制造的学生推荐 |
| 节省材料 | 先降低制造次数，观察日志和节点选择 |
| 避免误消耗 | 不确定时不要启用三阶段制造 |
