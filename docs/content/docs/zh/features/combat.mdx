title: 战斗
description: 竞技场、总力战、战术测试和高风险战斗任务。
---

战斗类功能会消耗挑战次数，且受队伍、账号练度和活动机制影响。不要在未验证的情况下加入无人值守调度。

| 功能     | 风险             | 建议                   |
| -------- | ---------------- | ---------------------- |
| 竞技场   | 消耗挑战次数     | 先确认排名、对手和队伍 |
| 总力战   | 机制复杂         | 只启用已验证 Boss 流程 |
| 战术测试 | 可能消耗全部票券 | 确认队伍编号和难度     |
