日程配置用区域矩阵决定哪些区域参与执行，以及各区域已执行次数。它会消耗日程次数并获得奖励。

  alt="日程配置，显示各日程区域在初级、普通、高级、特级中的启用状态和已执行次数"
/>

| 配置                 | 说明                                   |
| -------------------- | -------------------------------------- |
| 日程次数             | 控制本轮执行次数                       |
| 日程区域             | 控制初级、普通、高级、特级区域是否参与 |
| 优先选择收藏学生     | 优先进入收藏学生相关日程               |
| 优先选择高好感度学生 | 优先处理高好感度收益                   |

如果只想跑固定区域，关闭不需要的区域列。开启收藏或高好感优先时，先确认游戏内收藏状态。

## 指定角色日程

旧文档中“优先做指定角色日程”的思路是：先在游戏内或配置中明确目标角色，再让 BAAS 优先选择包含该角色的日程区域。

| 场景 | 建议 |
| ---- | ---- |
| 只跑固定区域 | 关闭其他区域，只保留目标区域 |
| 追指定角色好感 | 启用收藏学生或指定角色优先，并确认游戏内收藏状态 |
| 国际服 / 日服识别异常 | 先确认当前版本是否已经适配对应日程界面 |
| 模板缺失 | 提供 1280x720 PNG、目标角色可见、无弹窗遮挡的日程截图 |
