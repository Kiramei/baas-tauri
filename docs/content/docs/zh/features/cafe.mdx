咖啡厅偏向收益领取和好感度维护，整体风险较低，但邀请策略仍会影响培养目标。

<img

/>

| 配置           | 作用                             |
| -------------- | -------------------------------- |
| 领取奖励       | 自动领取咖啡厅收益               |
| 使用邀请券     | 按邀请设置邀请学生               |
| 允许换装       | 允许换装学生参与识别和邀请       |
| 启用二号咖啡厅 | 启用 2 号咖啡厅配置              |
| 摸头轮数       | 轮数越高越不容易漏摸，但耗时更长 |

邀请模式包括按学生名字、最高好感度、最低好感度和收藏学生。指定培养目标时，建议使用按学生名字并维护学生列表。

## 指定角色好感策略

旧文档中的经验策略仍然适用：

| 目标 | 做法 |
| ---- | ---- |
| 邀请指定角色 | 使用“按学生名字邀请”，或只收藏目标角色后使用“邀请收藏学生” |
| 一天多次摸指定角色 | 1 号和 2 号咖啡厅都配置目标角色；关闭自动使用邀请券；在调度中启用对应咖啡厅邀请任务 |
| 降低误邀请 | 不要同时维护过长的候选名单；确认换装学生是否允许参与 |

如果你的目标是尽可能多获取指定角色好感，通常需要同时配置咖啡厅、日程和制造：咖啡厅负责摸头与邀请，日程负责指定角色区域，制造负责角色喜欢的礼物。
