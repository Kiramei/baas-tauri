## 基础设置

| 控件             | 含义与可接受值                                                                | 导出字段                             |
| ---------------- | ----------------------------------------------------------------------------- | ------------------------------------ |
| 领取奖励         | 咖啡厅任务执行时领取累计收益                                                  | `cafe_reward_collect_hour_reward`    |
| 使用邀请券       | 允许在咖啡厅收益流程中使用邀请券；关闭不等于禁用所有独立邀请任务              | `cafe_reward_use_invitation_ticket`  |
| 允许学生更换服饰 | 游戏出现换装提示时允许替换学生的其他服装版本                                  | `cafe_reward_allow_exchange_student` |
| 允许重复邀请     | 游戏出现重复邀请提示时允许邀请已经在场的学生                                  | `cafe_reward_allow_duplicate_invite` |
| 启用二号咖啡厅   | 将二号店纳入处理并显示独立选项卡；应在游戏内解锁后启用                        | `cafe_reward_has_no2_cafe`           |
| 摸头轮数         | 整数 4–15，输入会限制在此范围。较多轮数可减少漏摸，但耗时更长；暂时留空不保存 | `cafe_reward_affection_pat_round`    |
| 摸头风格         | 普通互动或拖动礼物，选择互动方式，不是制造材料策略                            | `patStyle`                           |

关闭二号咖啡厅会隐藏其选项卡，不代表执行单独的删除操作；重新启用后可继续编辑其策略。这些开关说明任务行为，不证明邀请券或学生当前可用。

## 一号与二号咖啡厅邀请

两个咖啡厅各自保有邀请方式、收藏位置与指定学生列表。只有在基础设置中启用二号咖啡厅，才会显示二号店选项卡。

<img
  className="baas-screenshot"
  src="/media/desktop/zh/conditional-cafe-named.png"
  alt="一号咖啡厅按名称邀请：已添加的学生按选择顺序排列"
/>

| 方式     | 行为                         | 条件显示的控件           |
| -------- | ---------------------------- | ------------------------ |
| 最低好感 | 按游戏列表的好感升序选择学生 | 不显示指定学生与收藏位置 |
| 最高好感 | 按好感降序选择               | 不显示指定学生与收藏位置 |
| 收藏学生 | 从游戏内收藏列表邀请         | 收藏位置 1–5             |
| 按名称   | 按配置列表顺序尝试学生       | 学生标签与添加学生       |

第 N 个咖啡厅对应字段为 `cafe_reward_inviteN_criterion`、
`cafe_reward_inviteN_starred_student_position` 与 `favorStudentN`，N 为
1 或 2。收藏位置表示游戏内列表位置，不是学生编号。核对的后端在按名称
模式的列表为空时会回退到最低好感邀请，不代表“不邀请”。

## 学生选择器

选择按名称，再点击添加学生。搜索匹配后端为当前区服提供的名称。
游戏区服的命名与客户端界面语言独立，英文界面的国服配置仍可能显示中文学生名。

点击学生添加，再点一次移除；新选择会追加到偏好列表末尾。标签上的移除
图标也可删除该项。每次选择都会更新自动保存草稿，关闭按钮不会撤销选择。
需要优先某位学生时，应按期望顺序建立列表。

## 调度与检查

咖啡厅收益、一号咖啡厅邀请和二号咖啡厅邀请是独立调度项，需要分别检查
启用状态、下次执行与前后置任务。两个咖啡厅配置同一学生只是偏好，
不保证两次邀请都成功，也不代表好感可以无限获取，仍受游戏可用状态和冷却限制。

定向培养时，可将咖啡厅、日程与二阶段制造中的目标学生配合设置。
先单独运行一个已配置任务，核对日志中的邀请方式、识别名称、票券状态与结果。
选择器中存在学生名称，不证明账号持有该学生，也不证明当前可以邀请。
