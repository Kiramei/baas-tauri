模拟器配置用于让 BAAS 自动启动模拟器，并在多开场景下连接正确实例。

<img
  className="baas-screenshot"
  src="/cn/emulator-basic-settings.png"
  alt="模拟器配置弹窗，包含启动脚本时打开模拟器、模拟器多开、等待时间和模拟器路径"
/>

| 配置项               | 作用                       | 常见问题                |
| -------------------- | -------------------------- | ----------------------- |
| 启动脚本时打开模拟器 | 启动调度器时自动打开模拟器 | 路径错误会启动失败      |
| 等待模拟器启动时间   | 给模拟器预留初始化时间     | 太短会导致 ADB 连接失败 |
| 模拟器路径           | 模拟器可执行文件路径       | 不要选错辅助程序        |

## 多开

<img
  className="baas-screenshot"
  src="/cn/emulator-multi-instance-settings.png"
  alt="模拟器多开配置，包含模拟器类型和多开模拟器编号"
/>

启用多开时，模拟器类型、多开编号和 ADB 端口必须对应。支持 MuMu、MuMu 全球版、雷电、蓝叠、蓝叠国际版、夜神、逍遥 NAT 和 Windows Subsystem for Android。

## ADB 端口参考

自动扫描找不到设备时，手动填写 ADB 端口。旧后端文档中的常见端口如下：

| 模拟器              | 默认端口           |
| ------------------- | ------------------ |
| MuMu 模拟器 12 5.0+ | `5555`             |
| MuMu 模拟器 12      | `16384`            |
| MuMu 模拟器旧版     | `7555`             |
| 雷电模拟器          | `5555`             |
| 蓝叠模拟器          | `5555`             |
| 逍遥模拟器          | `21503`            |
| 夜神模拟器          | `62001` 或 `59865` |

多开端口通常按实例编号递增：

| 模拟器       | 端口计算                |
| ------------ | ----------------------- |
| MuMu 12 5.0+ | `5555 + 多开编号 * 2`   |
| MuMu 12      | `16384 + 多开编号 * 32` |

蓝叠、雷电等模拟器需要在模拟器设置中打开 ADB 调试。排查时先只启动一个实例，连接成功后再配置多开。
