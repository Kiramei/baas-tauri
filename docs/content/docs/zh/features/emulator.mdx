## 启动设置

| 控件             | 保存字段             | 取值与影响                                        |
| ---------------- | -------------------- | ------------------------------------------------- |
| 启动时打开模拟器 | `open_emulator_stat` | 允许后端初始化游戏环境时启动指定模拟器            |
| 启动等待时间     | `emulator_wait_time` | 有限、非负的秒数；前端也接受小数                  |
| 模拟器路径       | `program_address`    | 实际模拟器启动程序/路径，不是游戏 APK 或 ADB 程序 |

自行管理模拟器时可以关闭自动启动。延长等待时间不能修复错误的程序路径或设备序列号。

原生 Tauri 中，“选择”打开文件选择器，接受 `exe`、`bin`、`app` 或其他文件；取消不改变路径。WebUI 没有原生选择器，需要填写**后端所在机器**能访问的路径。界面接受路径，不代表后端机器上实际存在该文件或能够执行。

## 类别与多开

| 选项                          | 保存标识            |
| ----------------------------- | ------------------- |
| MuMu                          | `mumu`              |
| MuMu 国际版                   | `mumu_global`       |
| 蓝叠国服                      | `bluestacks_nxt_cn` |
| 蓝叠国际版                    | `bluestacks_nxt`    |
| 夜神                          | `yeshen`            |
| 逍遥 NAT                      | `xiaoyao_nat`       |
| 雷电                          | `leidian`           |
| Windows Subsystem for Android | `wsa`               |

类别（`multiEmulatorName`）不随多开开关隐藏。它们是客户端选项，并非保证后端支持所有模拟器版本和系统平台。

开启 `emulatorIsMultiInstance` 后显示实例编号（`emulatorMultiInstanceNumber`）。需填写非负整数，含义是**启动哪个实例**，不是要开几个实例。应与模拟器管理器、启动程序和 ADB 地址匹配。

关闭多开只隐藏编号，不清空数据；隐藏的编号为空或非法时仍会阻止该分类草稿提交。自动启动关闭时，等待时间也仍需合法。有效修改自动保存，编辑本身不启动模拟器。

## 确定真实 ADB 端口

优先查看模拟器管理器/设置并使用 ADB 检测，不要依赖历史默认值。以下仅供排查参考：

| 历史环境       | 常见历史端口       |
| -------------- | ------------------ |
| MuMu 12        | `16384`            |
| 其他 MuMu 版本 | `5555` 或 `7555`   |
| 雷电、蓝叠     | `5555`             |
| 逍遥           | `21503`            |
| 夜神           | `62001` 或 `59865` |

旧 MuMu 公式 `16384 + 实例编号 × 32`、`5555 + 实例编号 × 2` 都有版本前提，不是通用规则。本次文档验证的 MuMu 使用 `127.0.0.1:16384`，不能据此推断其他机器端口。

启动成功但 ADB 失败时，检查调试开关、设备授权、实例映射和启动日志。先验证一个实例，再配置多开。截图与控制设置见[脚本](./script)。
