---
title: 编队
description: 按侧栏顺序、按预设编队、按侧栏属性编队和属性队伍设置。
---

编队配置决定战斗任务如何选择队伍。编队错误会导致战斗失败、超时或卡住。

<img
  className="baas-screenshot"
  src="/cn/team-method-settings.png"
  alt="编队配置基础页，选择按侧栏顺序编队、按预设编队或按侧栏属性编队"
/>

| 编队方式       | 适合场景                   |
| -------------- | -------------------------- |
| 按侧栏顺序编队 | 账号队伍固定且顺序稳定     |
| 按预设编队     | 已在游戏内维护预设队伍     |
| 按侧栏属性编队 | 需要按敌方护甲属性切换队伍 |

## 属性编队

<img
  className="baas-screenshot"
  src="/cn/team-attribute-settings.png"
  alt="编队配置属性页，显示爆发、贯穿、神秘、振动等属性的队伍设置"
/>

属性编队适合推图、活动挑战或账号队伍强度差异较大的场景。修改后用低风险关卡验证一次。

## 选队逻辑

| 方式           | 规则                                         | 注意                                     |
| -------------- | -------------------------------------------- | ---------------------------------------- |
| 预设编队       | 按游戏内预设队伍和所需属性选择               | 不要改预设名称；确保队伍之间没有角色冲突 |
| 按侧栏属性编队 | 按敌方护甲需要选择爆发、贯穿、神秘、振动队伍 | 优先保证 Boss 队克制属性                 |
| 按侧栏顺序编队 | 依次选择侧栏第 1、2、3、4 队                 | 适合你自己已按关卡需求排好队伍的场景     |

旧文档推荐在普通/困难推图中使用“按侧栏顺序编队”时，按区域需要手动把游戏内队伍排好。例如 20 图普通关常见为队伍 1 爆发、队伍 2 贯穿；困难图可能需要第三队。
