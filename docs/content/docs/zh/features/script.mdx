脚本设置决定后端如何截图、如何点击和任务结束后如何处理环境。

<img
  className="baas-screenshot"
  src="/cn/script-runtime-settings.png"
  alt="脚本设置弹窗，包含截图间隔、自动启动、任务完成后操作、截图方式和控制方式"
/>

| 配置               | 说明                                                |
| ------------------ | --------------------------------------------------- |
| 截图间隔           | 间隔越短响应越快，但占用更高                        |
| 脚本开启时自动启动 | 打开脚本后自动进入调度运行                          |
| 任务完成后操作     | 不做操作、退出 BAAS、退出模拟器、同时退出、关闭电脑 |
| 截图方式           | 影响画面获取稳定性                                  |
| 控制方式           | 影响点击、拖动和输入方式                            |

如果识别失败、画面比例异常或点击无效，优先检查 16:9 画面比例、HDR、截图方式、控制方式和模拟器前台状态。

## 截图方式与控制方式

旧后端文档中的经验值仍可作为排查参考：

| 项目     | 可选项                            | 说明                                         |
| -------- | --------------------------------- | -------------------------------------------- |
| 截图方式 | `nemu`                            | MuMu 12 场景速度快、无损；需要匹配 MuMu 环境 |
| 截图方式 | `scrcpy`                          | 速度较快，但不是无损截图                     |
| 截图方式 | `adb` / `uiautomator2`            | 稳定但慢，适合保守排查                       |
| 截图方式 | `mss` / `pyautogui`               | PC 客户端窗口截图                            |
| 控制方式 | `adb` / `uiautomator2` / `scrcpy` | ADB 模拟器控制                               |
| 控制方式 | `nemu`                            | MuMu 12 专用控制，延迟低                     |
| 控制方式 | `pyautogui`                       | PC 客户端桌面鼠标控制                        |

如果日志持续输出 `tentative click` 但页面没有变化，先检查 MuMu 后台保活、游戏内设置、控制方式和窗口焦点。
