打开**配置 → 推图**。推图与活动是同一工作区的两个选项卡。编辑计划自动保存；**执行按钮会立即启动一次性任务并返回首页**，不是只启用调度列表中的任务。

## 推图计划

| 控件      | 操作与保存字段                                          |
| --------- | ------------------------------------------------------- |
| 手操 Boss | 需要你处理首领战，不能按无人值守通关理解；`manual_boss` |
| 普通推图  | 有序推图列表；`explore_normal_task_list`                |
| 困难推图  | 独立的有序列表；`explore_hard_task_list`                |

点击**添加区域**，选择区域以及整区或单关。普通新选项为 1–5 关，困难为 1–3 关；普通区域编号是三的倍数时额外提供 A 关。区域选项受后端支持范围及区服上限约束，并非无限开放。

上下图标调整行顺序，垃圾桶移除。切换区域时保留兼容的单关选项，否则回到整区。旧配置中超出正常选项的值可能继续显示；无法识别的旧项显示原文，查看它们并不会修复或验证。执行前应删除或替换过期项。

### 存储格式

| 目标      | 示例      | 含义                     |
| --------- | --------- | ------------------------ |
| 整区      | `15`      | 推进该区域后端支持的关卡 |
| 单关      | `16-3`    | 推进 16-3                |
| 普通 A 关 | `6-A`     | 推进普通第 6 区 A 关     |
| 有序列表  | `15,16-3` | 先第 15 区，再 16-3      |

这**不是**带次数的三段扫荡格式。`1-1-1` 不属于推图格式；[扫荡](./sweeps)有独立的次数编辑器。

普通/困难执行按钮遇到对应空列表会报错。非空时，客户端刷新待提交草稿，发送 `start_normal_task` 或 `start_hard_task`，然后打开首页。请求收到确认不代表关卡已经完成。

### 前置条件

推图遵循后端的地图移动路线，不只是点击游戏扫荡按钮。先解锁自动结束回合与自动战斗，准备正确编号的队伍，并选择受支持区域。普通区域选择器从后端范围起始值开始，常见为第 4 区。多队路线依赖队伍位置及[选队方式](./team)。

在路线支持时，后端检查三星、挑战与礼物并跳过已完成目标。一些困难路线可能需要多次进入才能完成全部目标，不能据此保证每区都一次完成或无需手动战斗。

## 剧情命令

| 按钮     | 立即发送的后端任务  |
| -------- | ------------------- |
| 主线剧情 | `start_main_story`  |
| 小组剧情 | `start_group_story` |
| 迷你剧情 | `start_mini_story`  |

**当前编辑器没有主线剧情章节编号输入框。** 高级后端配置可使用 `main_story_regions`；解析后列表为空时，核验后端使用区服对应的 `main_story_available_episodes`。数字是后端剧情篇章 ID，不是普通推图区域列表，不要对着不存在的界面字段粘贴旧章节表。

特殊剧情战斗及终章机制仍可能需要手动完成。发送一次性剧情命令前先停止其他任务，通过首页与日志确认实际结果。

## 活动

<img
  className="baas-screenshot"
  src="/media/desktop/zh/config-stage-tab-2.webp"
  alt="新版活动选项卡：活动名称、剧情/任务/挑战执行及属性数据"
/>

当前活动名来自所选区服的后端数据；有数据时，属性表合并展示剧情、任务与挑战条目。没有名称或表格不代表游戏一定没有活动，也可能是后端数据缺失或过期。

| 动作     | 立即发送的后端任务                 |
| -------- | ---------------------------------- |
| 活动剧情 | `start_explore_activity_story`     |
| 活动任务 | `start_explore_activity_mission`   |
| 活动挑战 | `start_explore_activity_challenge` |

这些按钮启动推图，不是活动扫荡。按钮存在也不能证明后端已支持当前活动；先核对活动版本、关卡结构、区服与队伍。走格子与非走格子挑战可能需要不同处理或手操。[扫荡](./sweeps)页面另行配置活动扫荡和体力分配。
