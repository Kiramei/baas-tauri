推图会进入关卡或战斗，属于高影响配置。修改后先手动运行一次，确认关卡、次数、队伍和日志都符合预期。

普通/困难关卡格式使用英文逗号分隔，例如 `1-1-1,1-2-3` 表示 1-1 执行 1 次、1-2 执行 3 次。

## 推图前置条件

普通图自动推图不是单纯扫荡，它会按固定路线移动队伍。启用前确认：

- 游戏内已经解锁自动结束回合和自动战斗。
- 普通推图通常从 4 区及以后更稳定。
- 游戏内队伍编号要按关卡需要从小到大排列；多队关卡中，队伍编号会影响坐标和移动顺序。
- 队伍选择逻辑要和 [编队](../team) 页面中的设置一致。

活动功能依赖当前版本活动识别。启用前确认活动名称、任务编号、服务器活动进度，以及是否需要手动处理 Boss。

## 关卡填写规则

旧后端文档中的填写规则仍适用于理解推图参数：

| 场景       | 格式                     | 示例                                |
| ---------- | ------------------------ | ----------------------------------- |
| 普通图推图 | 区域或区域-关卡          | `15,16-3` 表示依次处理 15 区和 16-3 |
| 困难图推图 | 同普通图                 | `15,16-3` 表示 H15 区和 H16-3       |
| 主线剧情   | 章节编号，用英文逗号分隔 | `2,3,6` 表示第一章、第二章、最终章  |

推图会自动检测三星、挑战任务和礼物领取等状态，已完成的关卡会跳过。困难图 1-13 章部分关卡可能需要重复进入才能同时完成三星、礼物和挑战任务；14 章以后通常一次即可完成。

## 主线剧情章节编号

主线剧情使用数字编号，并用英文逗号分隔：

| 数字 | 章节 |
| --- | --- |
| `1` | 第一部序章 |
| `2` | 第一章 |
| `3` | 第二章 |
| `4` | 第三章 |
| `5` | 第四章 |
| `6` | 最终章 |
| `7` | 第五章 |
| `8` | EX 章节 |
| `9` | 第六章 |
| `10` | 第二部序章 |
| `11` | 第零章 |
| `12` | EX 章节 |

自动推剧情可以处理大部分走格子流程，但最终章或特殊战斗可能仍需要手动完成。留空时会使用当前后端的默认配置。

## 活动识别

活动图通常只稳定支持“故事 / 任务 / 挑战”结构。挑战关卡如果不是走格子关卡，可能需要手动处理 Boss 或战斗。
