## 游戏区服

已有配置档的区服选择器**不可编辑**。请在新建配置档时选对区服；需要使用另一个游戏包时新建配置档。切换界面语言不会改变区服。

| 选项           | 对应游戏客户端         |
| -------------- | ---------------------- |
| 国服官服       | 中国大陆官方客户端     |
| 国服 B 服      | 中国大陆哔哩哔哩客户端 |
| 国际服         | 国际客户端             |
| 国际服青少年版 | 国际服青少年客户端     |
| 韩国 ONE 商店  | 韩国 ONE 商店客户端    |
| 日服           | 日本客户端             |

字段保存为 `server`。可以选择区服，不代表该服所有当前活动和任务都已实现。

## 地址、端口与 USB 序列号

| 输入情况           | 客户端解释                                   |
| ------------------ | -------------------------------------------- |
| 地址与端口都填写   | ADB `主机:端口`；端口需为 `0`–`65535` 的整数 |
| 只填写其中一个字段 | 作为设备/USB 序列号，而不是主机端口对        |
| 两者都空           | 非法，该分类不会提交                         |

首尾空白会去除。端口零虽然通过前端校验，不代表是可用 ADB 地址。本机模拟器地址常为 `127.0.0.1`，不同实例可能有不同端口；以模拟器实际设置为准，不要凭公式猜测。

有效编辑自动保存为 `adbIP`、`adbPort`。这是**游戏设备连接**，不是应用设置里客户端到后端的服务连接地址。

## 检测 ADB

1. 启动目标设备/模拟器，并开启其 ADB 调试。
2. 点击端口旁的检测图标打开弹窗。
3. 在弹窗内点击**检测 ADB**，仅打开弹窗不会扫描。
4. 等待结果，选择目标地址后自动填入编辑器并关闭弹窗。

含冒号的地址按最后一个冒号拆成主机和端口；不含冒号的序列号填入地址并清空端口。启动任务前核对结果。

第一次扫描前也会显示无结果提示。检测中按钮显示加载并禁用。没有结果可能是模拟器未开启、调试关闭、设备未授权/离线，或后端扫描未覆盖该端点。排查时可用 `adb devices` 核对准确序列号，不要默认任意结果都是正确实例。

## Android

Android 客户端根据配置档区服选择本机已安装的游戏包，使用 Shizuku 和 `android_local`。桌面 ADB 字段不能代替 Android 授权，也不是选择另一部手机的入口。本机游戏设置见 [Android 客户端](../guide/android)。

桌面端后续启动、截图和控制设置见[模拟器](./emulator)与[脚本](./script)。
