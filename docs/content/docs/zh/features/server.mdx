## ADB 检测

本机模拟器通常使用 `127.0.0.1`，多开实例通过不同端口区分。点击 ADB 检测后，根据检测结果选择实际在线设备。

### 选择游戏服务器 [step]

先选择与实际游戏客户端一致的服务器。区服不匹配会影响资源识别、功能入口和任务流程。

### 填写 ADB IP [step]

本机模拟器通常填写 `127.0.0.1`。远程设备或特殊桥接环境才需要填写其他地址。

### 填写或检测端口 [step]

单开和多开实例的端口可能不同。优先使用 ADB 检测确认当前在线设备，再把端口写入配置。

### 继续配置模拟器 [step]

检测到设备后，再进入模拟器和脚本设置。未检测到设备时，先检查模拟器 ADB 开关、端口、多开实例和控制方式。
