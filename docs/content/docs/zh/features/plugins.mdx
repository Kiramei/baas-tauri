桌面端从导航栏打开**插件**；Android 和窄屏从**设置 → 通用 → 插件**进入。目录列出内置与已安装插件、版本、兼容性及所需权限。浏览目录或安装 ZIP 无需先选配置档；启用、信任、设置和运行任务需要选定配置档。

## 启用与保存

1. 选择配置档，打开插件详情，核对插件来源和权限。
2. 启用插件，填写设置后点击**保存**。离开前确认保存结果。
3. 点击具体动作运行，查看排队、运行中、成功、失败或已取消的状态。

同一后端共用已安装的插件包；启用状态、设置和外部代码信任按配置档保存。导入配置档会保留设置，但会清除外部插件的信任与启用状态，需要重新确认。

设置被另一端修改时，保存可能提示版本冲突。重新加载并对照修改，避免用旧草稿覆盖新设置。切换登录会话后，原会话的结果不会写入新会话。

## 五个内置工具

| 插件 | 用途 | 使用前注意 |
| ---- | ---- | ---------- |
| 囤体 `baas.hoard-ap` | 根据目标时间规划体力来源、生成时间轴，扫描邮箱或执行计划 | 扫描邮箱会翻页读取，不领取邮件；选用快照作为规划基线前先核对。执行前会重新读取状态，识别不完整时停止；付费购买需要手动处理 |
| 自动推图 `baas.auto-push` | 普通、困难、主线剧情及活动关卡，也可从当前关卡或剧情继续 | 核对编队、简单模式和手动 Boss 设置；当前页面不受支持时会停止。取消或失败后恢复原配置，不会撤销游戏内已发生的操作 |
| 装备刷图规划 `baas.equipment-planner` | 按缺口生成刷图方案，编辑扫荡串后重新估算，并提供神名文字计算 | 内置掉落数据适用于国服；计算不会自动执行扫荡，其他区服不能直接套用国服掉率 |
| 库存管理计算器 `baas.inventory-calculator` | 计算 9×5 搜索棋盘中物品位置的概率，支持已发现矩形与旋转条件 | 这是搜索棋盘求解器，不会识别账号材料库存。超出计算资源限制会返回限制结果，不生成伪造的估算概率 |
| 主页编辑 `baas.home-editor` | 按配置档显示、隐藏及排序资源、任务和插件快捷入口 | 可拖动或用移动按钮调整顺序；运行控制、Android 游戏面板和日志保持可用 |

囤体的未来收益属于预测，不能视为已领取库存；执行中断或后端重启后，应重新核对状态并规划。邮箱较多时扫描可能持续数分钟。设备动作会使旧的读取缓存失效。

插件结果可能包含时间轴、表格或结构化数据；需要排查时可查看原始 JSON。日期时间按设备本地时区输入，体力日切还受所选游戏时区和日切时间影响。

## 本地 ZIP 与代码信任

安装前核实包来源、版本和权限。外部 Python 插件需要对当前配置档明确授予代码信任；已安装代码被修改后，原信任会失效。卸载会移除后端共用的包，也会影响其他配置档。

<Callout type="warn" title="仅运行可信代码">
  插件使用后端进程所属用户的权限。计算任务的独立进程用于处理崩溃、超时和取消，不提供安全沙箱。不要安装无法核实来源的 ZIP。
</Callout>

API v1 不会自动安装 Python 依赖或自动更新插件。首页快捷入口只打开对应插件，不会自动执行动作；插件停用或卸载后入口消失。旧后端若提示不支持插件，先[更新后端](./update)。开发格式见[插件接口](../reference/plugin-api)。
