BAAS 通过客户端、受管理的后端和设备连接执行自动化。本套文档以当前 `dev` 桌面工作区为依据；Android 的平台差异单独对照 `android-dev` 说明。

## 开始使用

1. [安装客户端并连接后端](./guide/install)。
2. [了解工作区](./guide/interface)，选择或创建[配置档](./features/profile)。
3. 设置[区服](./features/server)、[设备](./features/emulator)和[脚本方式](./features/script)。
4. [编辑任务行为](./guide/configuration)，然后[启用并调度任务](./guide/scheduler)。
5. 先启动少量任务，再检查[运行状态与日志](./features/home-runtime)。

在 Android 本机运行自动化，先阅读 [Android 客户端](./guide/android)。

## 语言与外观

文档入口优先使用已经保存的文档语言选择，然后检测浏览器语言偏好；无法匹配时使用英文。侧栏语言菜单可以切换中文或英文。文档支持独立的浅色和深色主题，应用演示统一使用浅色模式。
