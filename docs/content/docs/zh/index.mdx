## 维护原则

旧的本地 Wiki 不再作为主要维护入口。当前文档主源位于 `baas-tauri/docs`，使用 Fumadocs 生成网页文档站；Tauri 文档页默认加载这个网页文档站，并可在 Tauri 中弹出独立“百科文档”窗口。

## 运行关系

```mermaid
flowchart LR
  User["用户 / 配置档"] --> Client["BAAS Tauri 桌面端"]
  Client --> Home["主页运行控制"]
  Client --> Scheduler["调度器"]
  Client --> Config["独立功能配置"]
  Client --> Docs["网页文档 / Wiki"]
  Scheduler --> Backend["BAAS 后端服务"]
  Config --> Backend
  Backend --> ADB["ADB / 模拟器"]
  Backend --> Game["蔚蓝档案客户端"]
  Backend --> Client
```
