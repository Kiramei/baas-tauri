## 导航与配置档

导航图标分别打开主页、调度、配置与设置。悬停图标可以查看名称。标题栏中的侧栏按钮用于收起或展开配置档面板，并记住状态。宽窗口下，侧栏收起时悬停导航图标可以临时预览面板；移出或按 Escape 关闭临时面板。使用菜单或对话框时，预览面板会保持可用。

配置档列表决定当前展示哪个账号、区服与设备的数据。新增图标打开创建窗口；配置档旁的省略号打开重命名、复制、导出与删除操作。拖动配置档可以调整列表顺序。窄窗口中，配置档改为带滚动控件的横向列表。[配置档](../features/profile)介绍归档与账号隔离。

BAAS 菜单表示当前工作区。BAAS Raid 显示为开发中，暂时无法选择，也不会启动另一个总力战工具。

## 标题栏菜单

| 菜单 | 操作与行为                                             |
| ---- | ------------------------------------------------------ |
| 文件 | 新建、导入配置档；在支持的桌面构建中打开后端配置文件夹 |
| 编辑 | 撤销、重做、剪切、复制、粘贴、删除、全选及打开设置     |
| 视图 | 侧栏、前进后退、放大缩小、重置为 100%、全屏            |
| 帮助 | 文档及当前帮助入口                                     |

不可用的命令会禁用。编辑命令针对当前聚焦的可编辑控件或选区。在配置页面中，撤销与重做可以作用于配置档的配置历史；编辑器标题旁的箭头提供相同入口。对话框和配置档运行快捷键冲突会影响快捷键处理，应以[系统设置](../features/system)中的当前绑定为准。

标题栏还提供前进、后退以及原生最小化、最大化或还原、关闭控件，不同平台的窗口边框可能不同。关闭或最小化后的行为取决于托盘偏好；窗口不可见并不代表自动化已停止。需要结束任务时，先使用停止。

## 主页运行区

主页展示选中配置档与区服、启动或停止、任务状态、资产和日志。远程模拟器按钮打开设备画面；快捷键按钮打开配置档运行快捷键设置。

- 启动会启动这个配置档的调度器，并不表示全部任务立即执行。
- 停止会请求调度器结束运行，应结合状态与日志确认结果。
- 当前任务与队列由后端报告；空队列与服务断开不是同一种状态。
- 资产是带时间的读取结果，不能据此认定游戏内数值始终实时刷新。
- 日志跟随与导出影响日志查看，不影响任务执行。
- 视频画面正常不代表自动化使用的截图、输入方式已经配置正确。

详细操作见[主页与日志](../features/home-runtime)。

## 配置工作区

<img
  className="baas-screenshot"
  src="/media/desktop/zh/config-cafe.webp"
  alt="行内咖啡厅编辑器，显示分类搜索、选项卡与配置历史箭头"
/>

配置直接打开行内编辑器，分类列表与搜索保留在旁边。有多个模式的功能使用选项卡，例如基础、一号咖啡厅与二号咖啡厅。编辑短暂停顿后会自动发送修改，这个工作区没有通用保存按钮。无效或尚未输入完整的数值会先保留在本地，变为有效值后再提交。

使用撤销与重做箭头可以反向或重新应用当前配置档的编辑，也可以回到另一个分类中的修改。历史属于当前窗口，不是永久后端备份；产生新修改后会清空重做分支。[编辑配置](./configuration)介绍搜索、自动持久化、结构化编辑器和配置档边界。

## 设置工作区

设置将配置分类替换为常规、外观、快捷键、运行、更新和日志。打开设置时侧栏保持展开，离开后恢复之前的侧栏偏好。搜索可以跨分类查找设置并高亮匹配控件。

## 连接状态与紧凑布局

导航栏底部的连接指示器显示服务状态，打开关于 BAAS 可以查看版本。后端已连接和调度器空闲是两种状态；运行前需要确认配置档、任务和设备一致。

窗口变窄时，分类改用选择器，导航切换为紧凑布局，菜单也随可用空间折叠。配置档与编辑语义保持一致，长列表可能需要横向或纵向滚动。Android 另有平台专用的启动、游戏显示和权限流程，见 [Android 客户端](./android)。
