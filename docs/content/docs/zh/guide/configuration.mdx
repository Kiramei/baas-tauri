编辑前先打开配置并选择目标配置档。选中分类会在工作区内直接展示，标题旁同时显示配置档名称。这些控件决定任务如何执行；是否启用以及执行时间需要另到[调度](./scheduler)设置。

## 搜索与分类

搜索覆盖已翻译的分类名称、控件标签、帮助文字与选项卡名称，多个词会缩小匹配范围。按 Enter 打开首个结果，编辑器内会高亮匹配内容。清空搜索可恢复完整分类列表；没有搜索结果不会清空已有配置。

功能组包含咖啡厅、日程、商店、制造、竞技场、每日扫荡、总力战、制约解除决战、战术测试与好友清理。通用配置包含服务器、脚本、模拟器、推图、编队、推送与其他。相关模式通过选项卡切换，无需分别打开设置对话框。

## 自动保存与输入校验

修改会立即出现在编辑器中。同一组字段停止修改约 300 ms 后，有效变更以稀疏配置补丁发送。切换编辑器或隐藏、离开页面时会刷出待发送的有效修改。单纯打开编辑器不会把默认值写入后端。

行内工作区没有将所有编辑统一还原的取消操作，需要使用撤销恢复某次修改。功能内嵌对话框仍可有自己的确定或取消；调度详情对话框另行使用保存与取消。

暂时留空或无效的数值可以保留为可见草稿。例如脚本截图间隔必须是至少 0.1 秒的有限数值，无效草稿不会发送。补全后再检查，不要认为离开页面就代表无效值已保存。自动发送同样依赖正常后端连接；发生连接异常后，需要重新确认同步值。

## 撤销与重做

<MotionDemo locale="zh" />

标题旁的箭头和适用的编辑菜单命令操作当前配置档的配置历史。在防抖时间内连续修改同一字段，可以合并为一步。撤销也能回到另一个分类的编辑，工作区会打开对应分类。

- 撤销恢复较早草稿，并发送对应的有效旧值。
- 重做重新应用刚撤销的修改；产生新修改后会清空重做分支。
- 每个配置档拥有独立历史，切换配置档不会将一个档的修改应用到另一个档。
- 历史保存在当前窗口，最多记录 100 步，重启后不会作为审计日志保留。
- 后端更新可以替换无待提交编辑的面板，并使该分类的旧历史失效；当前窗口自身编辑的延迟确认不应覆盖更新的本地草稿。

大规模迁移或试验前应导出配置档归档。配置历史不能替代备份。

## 结构化编辑器

| 编辑器     | 操作                                                     | 运行前核对                                     |
| ---------- | -------------------------------------------------------- | ---------------------------------------------- |
| 扫荡计划   | 添加章节、关卡、次数，在支持的场景选择固定次数或最多     | 区服、关卡、体力与困难次数上限                 |
| 扫荡次数   | 选择跳过、固定、全部或支持的分配模式，替代旧式组合字符串 | 各地区与购买上限；活动分配可能消耗全部可用体力 |
| 推图计划   | 添加章节、关卡或整章                                     | 编队要求与关卡解锁状态                         |
| 优先级列表 | 选择项目，再通过控件或支持的拖动、键盘操作调整顺序       | 靠前项目优先尝试；可用项目取决于后端数据       |
| 商店选择   | 选择具体商品和刷新次数                                   | 货币、刷新消耗与选中商品数量                   |
| 学生选择   | 搜索并选择这个功能使用的学生                             | 区服学生列表、邀请方式与一号或二号咖啡厅       |
| 编队网格   | 按侧栏或预设位置设置攻击属性                             | 网格位置与游戏内已保存的编队对应               |

这些控件是后端配置的表示形式，不是游戏操作成功的预览。各功能页会说明具体字段及资源影响。
