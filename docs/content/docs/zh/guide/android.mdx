v0.0.7 起，BAAS Tauri 提供原生 Android 客户端。Android 端把前端界面、内置 Python 后端、更新器、无障碍自动化桥接和前台服务整合在一个 APK 中，适合直接在 Android 设备上运行或测试移动端自动化链路。

## 适用范围

Android 客户端和桌面端目标不同：

| 场景 | 建议 |
| --- | --- |
| 桌面模拟器日常托管 | 优先使用 Windows / macOS / Linux 桌面端 |
| Android 真机或 Android 环境本地运行 | 使用 Android APK |
| 需要观察后端日志和更新进度 | Android 端可直接查看启动终端和更新日志 |
| 需要稳定长时间后台运行 | 保持前台服务通知，不要让系统杀后台 |

## 安装 APK

### 下载对应版本 [step]

从 GitHub Releases 下载最新 Android APK。优先选择当前版本发布页里的 arm64 APK；如果设备架构不匹配，等待对应构建或使用桌面端。

### 允许安装应用 [step]

Android 系统可能要求允许浏览器或文件管理器安装未知来源应用。只对可信来源临时打开权限，安装后可以关闭。

### 首次启动 [step]

首次启动时，应用会准备内置后端运行环境。这个过程可能需要一点时间；不要在启动终端仍在输出时强制关闭应用。

## 必要权限

| 权限 / 状态 | 作用 | 异常表现 |
| --- | --- | --- |
| 无障碍服务 | 允许脚本执行部分自动化控制 | 脚本无法点击或切换状态 |
| 前台服务通知 | 保持后端和脚本不被系统过早终止 | 后端运行一段时间后断开 |
| 网络访问 | 下载更新、连接更新源和同步资源 | 更新失败或后端准备失败 |
| 存储 / 文件访问 | 保存运行时、日志和配置 | 配置或日志无法写入 |

不同 Android 版本对后台运行限制不同。如果脚本运行过程中频繁中断，检查系统电池优化、后台限制和通知权限。

## 启动和连接状态

Android 端启动后会尝试启动内置后端。界面连接状态、启动终端和系统日志可以帮助判断当前卡在哪一步：

- 启动终端持续输出：后端仍在准备或更新。
- 前端显示连接中：后端可能未完成启动、认证或传输连接。
- 后端断开后自动恢复：属于 v0.0.7 的可恢复传输行为；如果频繁发生，应保留系统日志排查。

## 通知栏脚本开关

Android 端支持通过通知栏控制脚本启动或停止。

使用前确认：

1. 应用已经打开并完成后端启动。
2. 前台服务通知存在。
3. 无障碍服务已启用。
4. 当前配置档和任务配置正确。

如果通知栏按钮无效，先回到应用内确认连接状态，再从应用内启动或停止脚本验证后端是否正常。

## 更新 Android 后端

Android 端更新过程会显示后端更新日志和字节进度。更新期间不要强制结束应用。

更新失败时：

- 切换更新源或 SHA 获取方式后重试。
- 检查网络代理和系统网络权限。
- 如果更新后界面没有恢复，关闭应用后重新打开。
- 保留启动终端、系统日志和更新日志。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| APK 无法安装 | 确认 Android 版本、CPU 架构和未知来源安装权限 |
| 后端一直准备中 | 等待日志停止；如果失败，保留启动终端日志 |
| 脚本无法点击 | 检查无障碍服务和通知栏脚本开关状态 |
| 运行一段时间后断开 | 检查前台服务通知、电池优化和后台限制 |
| 更新后仍显示旧状态 | 重启应用，再确认版本号和更新日志 |

更多集中排障见 [故障排查](../../reference/troubleshooting#android-客户端异常)。
