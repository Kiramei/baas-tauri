---
title: 文档入口
description: 通过桌面端帮助菜单，使用系统默认浏览器打开文档站。
---

独立文档站由 `baas-tauri/docs` 中的 Fumadocs 项目生成。BAAS Tauri 使用系统默认浏览器打开该网站。

## 打开文档

在桌面端标题栏选择“帮助 → 文档”。应用不再内嵌 Wiki 页面，侧边栏也不再显示文档导航项。

选择“帮助 → 关于 BAAS”或点击导航栏 Logo，会打开同一个关于弹窗，展示客户端、后端、连接和项目信息。

## 语言

文档站维护中文和英文，使用网站自己的语言菜单切换，与应用界面语言互相独立。

## 本地开发地址

本地开发时，文档站通常运行在：

```text
http://localhost:3000/docs/zh/
http://localhost:3000/docs/en/
```

构建应用时可用 `VITE_BAAS_DOCS_URL` 修改文档链接，原有 `VITE_BAAS_WIKI_URL` 覆写仍兼容已有部署。

## 打开失败排查

如果无法打开文档：

- 在浏览器中直接打开文档地址，确认网络或本地 dev server 是否可用。
- 如果是 GitHub Pages，确认仓库 Pages 已启用并且 `NEXT_PUBLIC_BASE_PATH` 与 Pages 路径一致。
- 如果是本地开发，确认 `docs` 目录下的 Next dev server 正在运行。
- 确认系统已设置默认浏览器；原生浏览器打开器失败时，应用会显示错误提示。
