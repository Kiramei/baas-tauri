title: 网页 Wiki
description: 在应用内查看网页文档，也可以使用系统默认浏览器打开。
---

BAAS Tauri 不再把旧的本地 Wiki 文章列表作为主要维护入口。侧边栏的“文档”页面会加载网页文档站，文档内容由 `baas-tauri/docs` 中的 Fumadocs 项目生成。

## 主窗口内嵌

进入侧边栏“文档”后，主窗口会显示网页文档站。这个模式适合一边配置任务，一边在同一个窗口内查说明。

文档页会显示：

- 标题“百科文档”。
- 当前文档站加载状态。
- 在浏览器中访问按钮。
- 加载失败提示和当前 Wiki 地址。

## 使用浏览器打开

点击“在浏览器中访问”后，系统默认浏览器会打开同一个文档站。应用内的文档保持原位，可继续在主窗口阅读或配置任务。

## 语言与回退

文档站只维护中文和英文。应用界面为日文、韩文、法文、德文或俄文时，文档内容回退为英文。文档站页面右上角的语言下拉框用于在中文和英文之间切换。

## 本地开发地址

本地开发时，文档站通常运行在：

```text
http://localhost:3000/docs/zh/
http://localhost:3000/docs/en/
```

正式部署到 GitHub Pages 后，Tauri 内的网页 Wiki 地址可以切换到部署后的 URL。

## 加载失败排查

如果文档页一直显示加载失败：

- 在浏览器中直接打开同一个 Wiki 地址，确认网络或本地 dev server 是否可用。
- 如果是 GitHub Pages，确认仓库 Pages 已启用并且 `NEXT_PUBLIC_BASE_PATH` 与 Pages 路径一致。
- 如果是本地开发，确认 `docs` 目录下的 Next dev server 正在运行。
- 如果浏览器可以打开但内嵌页面失败，优先检查 WebView2、网络代理和 iframe sandbox 限制。
