功能配置决定任务如何执行，调度决定它是否参与当前配置档的自动化以及何时有资格执行。启动或停止调度器是独立的运行操作。

## 任务列表

当前界面使用一个列表，启用任务排在前面，禁用任务显示在分隔线之后。默认排序在各组内按优先级升序排列；时间排序在各组内按下次执行时间升序排列。相同排序值保留原顺序，排序偏好会被记住。

搜索匹配任务显示名称、后端事件名称和函数标识。启用数与总数统计整个配置档，不仅统计当前搜索结果。清空搜索可恢复完整列表。

| 控件             | 结果                                                            |
| ---------------- | --------------------------------------------------------------- |
| 行内开关         | 立即启用或禁用这个任务                                          |
| 行内日期时间     | 设置这个任务的下次执行时间，界面显示本地时间，持久化为 Epoch 秒 |
| 行内齿轮         | 打开任务调度详情                                                |
| 批量启用或禁用   | 启用全部任务；已经全部启用时改为禁用全部                        |
| 重置时间图标     | 将全部任务的下次执行时间设为现在                                |
| 新任务策略选择器 | 为后续新增的任务定义选择启用、禁用或后端默认状态                |
| 工作流图标       | 打开全屏图编辑器                                                |

批量开关和重置时间作用于整个配置档的任务列表，包含搜索隐藏的任务，不是仅操作搜索结果。启用任务不会验证游戏配置；重置时间可能让消耗资源的任务再次变为可执行。

## 运行状态

概览显示后端报告的当前任务与等待队列，不是根据前端当前显示顺序推算。禁用任务、修改时间或绘制依赖都不会自动发送停止。如果需要当前执行结束后再调整流程，应先停止调度器。

## 调度详情

齿轮打开的对话框使用独立草稿，保存后应用改动字段并关闭，取消或关闭则放弃这个对话框的草稿。这与功能配置工作区的自动保存不同。

| 字段         | 含义                                           |
| ------------ | ---------------------------------------------- |
| 事件名称     | 只读的任务标识或显示名                         |
| 下次执行     | 配置的最早可执行时间，不保证严格在这个时刻开始 |
| 优先级       | 默认排序参数，较小的值排在前面                 |
| 执行间隔     | 两次可执行之间的秒数，应填写非负值             |
| 每日重置     | 一个或多个每日重置时间点                       |
| 禁用时间范围 | 在这些时间范围内抑制任务触发                   |
| 前置任务     | 使用函数标识引用的有序前置任务                 |
| 后置任务     | 使用函数标识引用的有序后续任务                 |

时间与依赖规则由后端调度器判断，队列、未满足条件、当前执行和失败处理都会影响实际启动时刻。节点在画布上靠左本身不构成调度规则。

## 工作流编辑器

  className="baas-screenshot"
  src="/media/desktop/zh/scheduler-workflow.png"
  alt="原生工作流编辑器中的任务节点、独立前后置端口、自动布局、缩略图与缩放控件"
/>

每个任务有独立的前置与后置端口行，从右侧输出连接到左侧同类型输入。

| 连线                                | 存储关系                     | 含义              |
| ----------------------------------- | ---------------------------- | ----------------- |
| A 的右侧前置端口到 B 的左侧前置端口 | 将 A 追加到 B 的 `pre_task`  | A 是 B 的前置任务 |
| A 的右侧后置端口到 B 的左侧后置端口 | 将 B 追加到 A 的 `post_task` | B 在 A 之后执行   |

编辑器拒绝自连接、同类型重复关系、循环依赖、未知任务和端口类型不匹配。配置中已经存在的循环或失效引用会显示警告，便于检查。

选中连线后可使用线上删除控件，或工具栏中的断开。删除连线仅移除对应关系，不删除任务。图编辑器没有将 Delete 键绑定为删除节点。

拖动节点可以调整位置，缩放、适应视图和缩略图用于查看大图。自动排列重新计算布局并使图进入视野。位置按后端身份与配置档保存在本地，与任务配置分开。移动或排列节点不会改变任务优先级或依赖列表的顺序。

关系变更与任务开关会立即向后端发送补丁；关闭工作流不是取消操作。从节点打开的调度详情仍使用独立的保存与取消。

## 首次运行

核对区服与设备后，可以从邮件或奖励领取等少量任务开始。启用商店、扫荡、战斗、好友清理或单次操作前，先阅读相应配置；这些任务可能消耗货币、体力、票券、挑战次数或修改账号状态。每次修改后先查看任务结果与日志，再扩大启用范围。
