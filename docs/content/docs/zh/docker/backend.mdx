---
title: 后端与 OCR 准备
---

首次安装默认克隆稳定版后端 `pur1fying/blue_archive_auto_script` 的 `master` 分支。需要开发版时，将容器的 `command` 设为 `https://github.com/Kiramei/baas-dev.git`。已有数据卷沿用其 Git 来源，分支由 `BRANCH` 指定。已有 Git 工作区只进行快进更新，不自动丢弃或暂存本地修改。完整 OCR 安装会保留；缺少文件时按启动配置尝试修复，已有配置和输出保留。

完全离线部署可在 `/app/setup.toml` 中使用：

```toml
[general]
no_update = true
```

这会禁止启动阶段 Git 更新及 OCR 下载，空目录无法靠它完成安装。需要先准备有效后端 `main.service.py`、Python 依赖及匹配架构的 OCR。`BAAS_SERVICE_OCR_UPDATE_CHECK=0` 只跳过后端 OCR 更新检查，不能代替完整的离线文件准备。
