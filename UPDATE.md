## v0.0.1

> This is a test version

### ✨ New Features

1. 🧭 **Workflow-Based Installation and Update UI**
   Introduced a guided workflow experience for smoother installation and update operations.

2. 🔐 **Enhanced Security with HMAC Authentication and Encrypted Communication**
   Added HMAC-based authentication and encrypted data transmission to improve overall security.

3. ⚡ **High-Speed Communication via Persistent WebSocket Connections**
   Improved communication efficiency with long-lived WebSocket connections for faster and more stable data transfer.

4. 🖥️ **Remote Monitoring and Control with Modified Ws-scrcpy**
   Integrated a customized Ws-scrcpy solution to support remote device monitoring and control.

5. 🚀 **Modern, Lightweight Desktop Experience Powered by Tauri**
   Rebuilt with Tauri for a modern UI, faster performance, and lower resource consumption.

### 🛠️ Bug Fixes

1. 🧩 **Single-Instance Mode**
   Added single-instance support to prevent redundant processes and unnecessary resource usage.

2. 📦 **Installation Issues from the Previous Qt Version**
   Fixed installation-related problems present in the earlier Qt-based version.

3. 🪟 **Stability Improvements for Tab Operations**
   Resolved crashes that could occur when closing and reopening tabs.
