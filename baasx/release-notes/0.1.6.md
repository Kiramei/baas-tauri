## English

- Maintenance release from `main` under the Git tag `baasx-0.1.6`. The bundled native helper is synchronized with the main branch.
- Upgrade npm installations with `npm update -g @kiramei/baasx`, or verify `SHA256SUMS` and replace the complete standalone archive.
- Linux ARMv7 hard-float supports remote connections and terminal use. Managed local setup requires a matching OCR prebuild and validated backend dependencies.
