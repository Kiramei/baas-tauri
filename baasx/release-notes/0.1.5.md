English:

- Add Linux ARMv7 hard-float support. `armv7l` and Debian `armhf` share the `Linux-ARMV7L` assets and `@kiramei/baasx-linux-arm` npm package.
- ARM32 standalone archives bundle Node.js 22.23.5 and the ARMv7 Rust helper. The `-node.tgz` attachment requires ARM32 Node.js 20.3+. Existing x64 and ARM64 distributions remain available.
- ARM32 requires GNU/Linux ARMv7 hard-float, glibc 2.35+, `libstdc++6`, and `libatomic1`.
- ARM32 supports the workbench, remote connections, configuration, tasks, scheduling, and logs. Managed local installation/recognition remains unavailable because there is no upstream ARM32 OCR prebuild or validated backend dependency stack.
- Upgrade BAASX with `npm update -g @kiramei/baasx` or replace the complete archive. `/update` targets a supported local backend environment. Releases include `SHA256SUMS` and no `.sig` files; the desktop client's signatures are unchanged. Unscoped npm publication remains on hold.
