- `/detach` 后可关闭终端，任务继续运行。用 `baasx` 恢复，或用 `baasx attach -f` 接管。
- 启动时提示终端和本地后端更新。用 `baasx self update` 更新终端，也可在工作台跳过该版本。
- `/stop` 和 `baasx stop` 立即提交停止请求。首页移除了任务和指令计数，总览中可查看可用更新。

### 从 0.1.6 升级

npm 用户可运行 `npm install -g @kiramei/baasx@0.1.7`。独立版用户请下载对应平台的归档，按 `SHA256SUMS` 校验后整体替换解压目录。从 0.1.7 起，独立版自更新会校验下载，GitHub 无法访问时可从项目的 CNB 镜像获取发行包。

## English

- Use `/detach` to leave the workbench while tasks keep running. Run `baasx` to resume, or `baasx attach -f` to take over from another terminal.
- The workbench checks for BAASX and local backend updates at startup. Install an available BAASX update, defer it for the session, or skip that version. Run `baasx self update` to update the terminal from the command line.
- `/stop` and `baasx stop` now submit the stop request immediately. The home screen drops the task and command counts and shows available updates in the overview.

To upgrade from 0.1.6, run `npm install -g @kiramei/baasx@0.1.7` for an npm installation. For standalone installations, verify the platform archive against `SHA256SUMS` and replace the extracted directory. Starting with 0.1.7, standalone updates verify the archive and can download it from the project’s CNB mirror if GitHub is unavailable.
