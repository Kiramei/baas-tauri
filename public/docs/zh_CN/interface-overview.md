# 界面总览

## 主页

主页用于启动或停止当前配置档，查看正在运行的任务、等待队列、资产信息、远程模拟器画面和实时日志。日志支持自动滚动和导出。

## 调度

调度页管理每日任务。你可以搜索任务、按默认顺序或时间排序、启用或禁用任务、修改执行时间，并打开任务级参数弹窗。

## 配置

配置页分为功能设置和通用设置。功能设置包括咖啡厅、日程、商店、制造、竞技场、日常、总力战、战术测试和好友白名单；通用设置包括服务器、脚本、模拟器、推图、编队、推送和其他。

## 设置

设置页包含主题、语言、UI 缩放、主题色、背景图、低性能模式、远程画面解码器、更新源、MirrorC CDK、SHA 测试和客户端更新。

## 文档

文档页默认打开网页 Wiki。Tauri 版本可以将文档弹出到独立系统窗口，主窗口会显示已在单独窗口打开。
