# 功能配置

## 通用模块

- 服务器：选择区服并配置 ADB IP 与端口。
- 模拟器：配置模拟器路径、多开类型、实例编号、启动等待时间和是否自动打开。
- 脚本：配置截图方式、控制方式、截图间隔、自动启动和任务结束后的动作。
- 推图：配置普通关、困难关、剧情、任务、挑战和活动关卡。
- 编队：按侧栏顺序、预设或侧栏属性编队。
- 推送：配置 JSON 推送和 ServerChan。

## 日常与战斗模块

- 咖啡厅：领取奖励、邀请学生、摸头、二号咖啡厅和邀请策略。
- 日程：配置区域、次数、收藏学生和高好感优先。
- 商店：配置普通商店和竞技场商店购买。
- 制造：配置制造次数、阶数、材料、颜色和优先级。
- 竞技场：配置对手编号、刷新次数和等级差。
- 日常：配置普通/困难扫荡、悬赏通缉、学院交流会、特殊委托和活动扫荡。
- 总力战：配置难度。
- 战术测试：配置难度、队伍编号和挑战券使用。
- 好友白名单：保留指定好友码，避免自动清理。
