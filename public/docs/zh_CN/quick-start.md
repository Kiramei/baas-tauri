# 快速开始

BAAS Tauri 是蔚蓝档案自动化的桌面控制端。客户端负责配置、调度、日志、更新和远程画面；后端服务负责 ADB、截图、识别和任务执行。

## 首次使用

1. 打开 BAAS Tauri。
2. 在安装向导中选择安装目录，等待环境准备完成。
3. 设置或输入 BAAS 密钥。
4. 创建配置档，选择服务器和模拟器。
5. 在配置页完成服务器、模拟器、脚本和基础任务设置。
6. 在调度页启用要运行的任务。
7. 回到主页点击启动。

## 连接检查

侧边栏底部显示服务连接状态。若一直处于连接中，请检查后端是否启动、端口是否被占用、密钥是否一致，以及日志中是否有认证或路径错误。
