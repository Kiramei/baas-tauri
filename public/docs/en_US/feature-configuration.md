# Feature Configuration

## General modules

- Server: choose game server and configure ADB IP and port.
- Emulator: configure emulator path, multi-instance type, instance number, startup wait time, and auto-open.
- Script: configure screenshot method, control method, screenshot interval, auto-start, and completion action.
- Stage: configure normal, hard, story, mission, challenge, and event stages.
- Team: form teams by sidebar order, preset, or sidebar attributes.
- Push: configure JSON push and ServerChan.

## Daily and combat modules

- Cafe: collect rewards, invite students, pat students, Cafe 2, and invitation strategy.
- Lessons: configure area, attempts, starred students, and high affection priority.
- Shop: configure common shop and Tactical Challenge shop purchases.
- Crafting: configure count, phase, material, color, and priority.
- Arena: configure opponent number, refresh count, and level difference.
- Daily: configure normal/hard sweeps, bounty, commissions, special missions, and event sweeps.
- Total Assault: configure difficulty.
- Joint Drill: configure difficulty, team number, and challenge ticket usage.
- Friend Whitelist: keep specified friend codes during cleanup.
