# Quick Start

BAAS Tauri is the desktop control app for Blue Archive automation. The client handles configuration, scheduling, logs, updates, and remote display; the backend service handles ADB, screenshots, recognition, and task execution.

## First use

1. Open BAAS Tauri.
2. Choose the install directory in the setup wizard and wait for environment preparation.
3. Set or enter the BAAS key.
4. Create a profile and choose server and emulator.
5. Configure server, emulator, script, and base tasks.
6. Enable tasks in Scheduler.
7. Return to Home and click Start.

## Connection check

The lower-left sidebar shows service connection state. If it stays connecting, check whether the backend is running, the port is occupied, the key matches, and whether logs show authentication or path errors.
