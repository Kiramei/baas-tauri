# Interface Overview

## Home

Home starts or stops the active profile and shows the running task, waiting queue, assets, remote emulator display, and realtime logs. Logs can auto-scroll and export.

## Scheduler

Scheduler manages daily tasks. You can search tasks, sort by default order or time, enable or disable tasks, change execution time, and open task-level parameter dialogs.

## Configuration

Configuration is split into Feature Settings and General Settings. Feature Settings include Cafe, Lessons, Shop, Crafting, Arena, Daily, Total Assault, Joint Drill, and Friend Whitelist. General Settings include Server, Script, Emulator, Stage, Team, Push, and Other.

## Settings

Settings include theme, language, UI zoom, theme color, background image, low performance mode, remote display decoder, update sources, MirrorC CDK, SHA tests, and client updates.

## Docs

Docs opens the web Wiki by default. In the Tauri version, it can detach into a normal system window while the main window shows that the docs are already open separately.
