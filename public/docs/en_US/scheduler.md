# Scheduler

Scheduler decides which tasks run for the active profile and when each task runs next.

## Areas

- Task overview: current task and waiting queue.
- Inactive tasks: tasks that will not run.
- Active tasks: tasks executed by the scheduler.
- Search and sort: quickly locate tasks.

## Operations

- Click arrows to enable or disable one task.
- Click arrows near column titles to move all tasks.
- Use date-time controls to change execution time.
- Click the gear button to edit task parameters.
- Click refresh to set task times to now.

Start with low-risk tasks such as cafe, mail, shop, lessons, and sweeps. Validate event, Total Assault, Arena, and Joint Drill tasks individually before adding them to the daily schedule.
